# 共通テスト 過去問演習・点数集計（星飛ぶの勉強部屋）

**サイトはこちら → https://hoshitobu.github.io/hoshitobu-survey/**

共通テスト（2021〜2026）の過去問を、年度・科目ごとにまとめたページです。

- [年度・科目ごとの平均点・偏差値・正答率](https://hoshitobu.github.io/hoshitobu-survey/kyotsu/index.html)：点数を入れると全国の偏差値と順位が出ます
- [点数をマス目に入れて平均と比べる](https://hoshitobu.github.io/hoshitobu-survey/kakomon.html?view=quick)
- [時間を計って過去問を解く](https://hoshitobu.github.io/hoshitobu-survey/kakomon.html)
- [集計を見る](https://hoshitobu.github.io/hoshitobu-survey/results.html)

平均点・正答率などの数値の出典：大学入試センター「実施結果の概要」「科目別成績分布」「設問別得点率及び正答率」
