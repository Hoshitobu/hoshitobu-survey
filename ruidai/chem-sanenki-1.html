化学　酸塩基で反応式を書く

酸塩基の反応は H+ のやりとりで、生成物と係数は「何が H+ を渡し、何が受け取るか」で決まる。気体の製法・塩の液性・両性の反応を、同じ道具で書く。

① 基礎ドリル

基礎：反応式を1本ずつ（6つの形）

目標は、材料を見たら、何が H+ を渡して何が受け取るかが言えて、反応式が書けること。そのために、同じ手順を何度もくり返して量を貯める。

左の時計（スマホは画面の下の帯）を動かして解く。「自分の答えを書いた」を押した時点の時間が、その問題の時間になる。1問 60 秒以内に「合っていた ○」をつけると、解いた数の「時間内」に数える。

材料が書いてある。H+ や OH− のやりとりを決めて、反応式を書け。選択式の問いは、番号で答えよ。

② 組み合わせ

組み合わせ：気体・液性・両性・量をつなぐ

共通テストの化学（本試 第3問）と同じ作り：1つの組み合わせが本番の「問」1つにあたり、分けるときは a・b（・c）。空欄は解答番号の四角（例：16）で、答えは解答群の番号（①〜）を選ぶ。数値も「最も適当な数値」を選ぶ形が中心で、有効数字の数字を1桁ずつ選ぶ形はテーマに1問ほど。解答欄で選んで「答え合わせ」を押すと、解答番号ごとに〇×が出て、そのあと解説が開く。難しさの札は A（基本の判断1つずつ）・B（2つの道具をつなぐ）・C（本番の正答率の低い問の作り：条件の読み替え・誘導の間・紛らわしい解答群）。

  • 難しさ A誘導どおりに、1つの小問に1つの定理で進む。
  • 難しさ B前の小問の結果を使い、最後は条件を変えて、誘導なしでもう一度。
  • 難しさ C本番の正答率の低い設問の作り：条件を自分で読み替える・誘導の間があく・図を自分でかく・紛らわしい解答群・最後は符号や場合を変えてもう一度。
  • 気づく図や式の中の引き金を見つける（例：円に内接 → 対角の和が 180°）。
  • 振り返る前の小問の結果や手順を、もう一度使う。
  • 誘導に乗る小問の流れの意味を読み、次に何を求めるかを見通す。
  • 自力で作る誘導が無い。自分でブロックに分けて、小問を立てる。

弱酸・弱塩基の遊離

弱酸・弱塩基の遊離

強い酸 ＋ 弱い酸の塩 → 強い酸の塩 ＋ 弱い酸
強い塩基 ＋ NH4+ の塩 → 強い塩基の塩 ＋ NH3 ＋ H2O

引き金（こういうとき使う）

  • 塩に酸（または強塩基）を加えて、気体や弱い酸ができる
  • CO2・SO2・H2S・NH3 の製法

意味

H+ が、強い酸から弱い酸の陰イオンへ、または NH4+ から OH− へ移る。
どの原子の酸化数も変わらない。

落とし穴

H2CO3 や H2SO3 は不安定で、H2O と気体に分かれて出てくる。
硝酸は酸化剤なので、FeS や Na2SO3 とは酸化還元になる。

揮発性の酸の遊離

揮発性の酸の遊離

不揮発性の酸（濃硫酸）＋ 揮発性の酸の塩 →（加熱）→ 不揮発性の酸の塩 ＋ 揮発性の酸（気体）

引き金（こういうとき使う）

  • 塩に濃硫酸を加えて加熱する
  • HCl・HF の製法

意味

進む理由は酸の強さではなく、できた酸が気体として出ていくこと。

落とし穴

「強い酸が弱い酸を追い出す」と考えると、NaCl + H2SO4 → NaHSO4 + HCl の向きが説明できない（HCl も強酸）。

中和と塩の液性

中和と塩の液性

酸の H+ ＋ 塩基の OH− → H2O、残りのイオンが塩。液性は、弱い酸・弱い塩基から出たイオンで決まる

引き金（こういうとき使う）

  • 酸と塩基（酸性酸化物・塩基性酸化物を含む）を混ぜる
  • 塩の水溶液が酸性か塩基性か

意味

強酸＋強塩基の塩は中性、強酸＋弱塩基の塩は酸性、弱酸＋強塩基の塩は塩基性。
酸性酸化物は塩基と、塩基性酸化物は酸と中和する。

落とし穴

NaHCO3 は「酸性塩」でも水溶液は弱い塩基性、NaHSO4 は酸性。
塩の名前では決まらず、残った陰イオンが H+ を出すか受け取るかで決まる。

両性（Al・Zn）

両性（Al・Zn）

酸と酸化物・水酸化物 ＋ 酸 → 塩 ＋ H2O
強塩基と酸化物・水酸化物 ＋ 強塩基 → ヒドロキシド錯イオン[Al(OH)4]−・[Zn(OH)4]2−

引き金（こういうとき使う）

  • Al・Zn の酸化物・水酸化物・イオン
  • NaOH 水溶液を過剰に加えると、沈殿が溶ける

意味

酸からは H+ を受け取る塩基として、強塩基からは OH− を受け取る酸としてはたらく。
錯イオンの形は覚える。

落とし穴

アンモニア水を過剰に加えても Al(OH)3 は溶けない（Zn(OH)2 は [Zn(NH3)4]2+ になって溶ける）。
