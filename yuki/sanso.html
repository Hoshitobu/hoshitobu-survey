酸素を含む化合物

酸素を含む化合物の反応は、どの基で起こるかが決まっている。−OH のついた炭素の H を数えれば酸化の行き先が、検出反応が見ている形を探せば結果がわかる。

酸化の道すじ

アルコールを酸化すると、−OH がついた炭素の H の数によって行き先が分かれる。第1級アルコールはアルデヒドを経てカルボン酸に、第2級アルコールはケトンになり、第3級アルコールは酸化されにくい。

酸化−2H酸化＋O
酸化−2H

酸化剤には、硫酸酸性の二クロム酸カリウム水溶液などを使う。カルボン酸とアルコールからはエステルが、2 分子のアルコールからはエーテルができる。

アルコール・アルコールの酸化・エーテル・アルデヒドとケトン・ヨードホルム反応・カルボン酸・エステル・油脂・セッケン・検出反応は、どこを見ているか・よく出る疑問・過去問で確かめる

先に要るもの：構造と異性体

アルコール

炭化水素の H をヒドロキシ基 −OH で置き換えた化合物で、ベンゼン環に −OH が直接ついたもの（フェノール類）は含めない。−OH の数で 1 価・2 価・3 価、−OH がついた C に結合している炭化水素基の数で第1級・第2級・第3級に分ける。

アルコールの性質覚える

−OH どうしが水素結合をつくるので、分子量が同じくらいの炭化水素や、構造異性体のエーテルより沸点が高い。炭素数の少ないアルコールは水によく溶け、水溶液は中性である。炭素数が多くなると水に溶けにくくなる。

ナトリウムと反応する場所場所を探す
2C2H5OH + 2Na → 2C2H5ONa + H2

単体の Na は −OH の H と置き換わり、H2 が出る。生じる C2H5ONa はナトリウムエトキシドである。−OH をもたないエーテルは Na と反応しないので、アルコールとエーテルを区別できる。−COOH の H も Na と反応する。

温度で変わる脱水数える覚える
濃硫酸160〜170℃+
2C2H5OH → C2H5OC2H5 + H2O　（濃硫酸、約130℃）

同じエタノールと濃硫酸でも、160〜170℃ では 1 分子の中から H2O がとれてエチレンになり（分子内脱水）、約 130℃ では 2 分子から H2O が 1 つとれてジエチルエーテルになる（分子間脱水、縮合）。何分子から何がとれたかは、生成物の分子式を数えればわかる。温度と生成物の組合せは覚える。

メタノール・エタノールの製法覚える
CO + 2H2 → CH3OH　（触媒、加熱・加圧）
CH2=CH2 + H2O → CH3CH2OH　（リン酸触媒、加熱・加圧）
C6H12O6 → 2C2H5OH + 2CO2　（アルコール発酵）

メタノールは一酸化炭素と水素から、工業用のエタノールはエチレンへの水の付加でつくる。飲料用のエタノールは、グルコースなどの糖のアルコール発酵でつくる。2 価のエチレングリコール HO(CH2)2OH と 3 価のグリセリン C3H5(OH)3 も、どちらも水によく溶ける粘性のある液体である。

アルコールの酸化

アルコールの酸化でとれるのは、−OH の H と、−OH がついた C の H の 2 個である。その C に H がいくつあるかを数えれば、何になるかが決まる。

第1級・第2級・第3級の酸化数える場所を探す
アルコール−OH がついた C の H酸化すると例
第1級2 個H が 1 個残ってアルデヒド、さらに酸化されてカルボン酸エタノール → アセトアルデヒド → 酢酸
第2級1 個ケトンで止まる2-プロパノール → アセトン
第3級0 個酸化されにくい2-メチル-2-プロパノール

メタノールは第1級として酸化され、ホルムアルデヒドを経てギ酸になる。焼いて表面を酸化銅(Ⅱ)にした銅線をメタノールの蒸気に触れさせると、ホルムアルデヒドができる。

CH3OH + CuO → HCHO + H2O + Cu

2026 年本試験 第5問 問3a の決め手：「第一級はアルデヒド、第二級はケトン」。

エーテル

O 原子に 2 つの炭化水素基が結合した R−O−R′ の形の化合物である。

アルコールとの見分け場所を探す

同じ炭素数のアルコールとは構造異性体の関係にある。−OH をもたないので、分子間で水素結合をつくらず沸点が低い。Na とは反応せず、酸化もされにくい。水に溶けにくく、有機化合物をよく溶かすので溶媒に使う。ジメチルエーテルの例のように、分子式だけではアルコールと区別できないので、Na との反応で −OH の有無を確かめる。

ジエチルエーテル覚える

ジエチルエーテル C2H5OC2H5 は揮発性の液体で、引火しやすく、麻酔作用がある。抽出の溶媒によく使われる。

アルデヒドとケトン

カルボニル基 C=O をもつ化合物のうち、カルボニル基の C に H が 1 個以上ついたものがアルデヒド（−CHO）、2 つの炭化水素基がついたものがケトンである。アルデヒドは酸化されやすく、相手を還元する（還元性）。ケトンはこれ以上酸化されないので、還元性を示さない。

銀鏡反応とフェーリング液の還元場所を探す
2[Ag(NH3)2]+ + RCHO + 3OH− → 2Ag + RCOO− + 4NH3 + 2H2Oイオン反応式
2Cu2+ + RCHO + 5OH− → Cu2O + RCOO− + 3H2O

アンモニア性硝酸銀水溶液にアルデヒドを加えて温めると、Ag+ が還元されて銀が析出し、試験管の内側が鏡のようになる（銀鏡反応）。フェーリング液に加えて加熱すると、Cu2+ が還元されて酸化銅(Ⅰ) Cu2O の赤色沈殿ができる。どちらも、見ているのは −CHO の部分である。−CHO はカルボキシ基 −COO− に変わる。

間違えやすい所：ギ酸は還元性を示す場所を探す

ギ酸 HCOOH はカルボン酸だが、H と C＝O の組、つまりホルミル基と同じ構造を分子の中にもっている。そのため還元性を示し、銀鏡反応を起こす。「酸」という名前で判断せず、−CHO の形があるかを構造式の上で探す。酢酸 CH3COOH にはこの形が無く、還元性を示さない。

ホルムアルデヒド・アセトアルデヒド・アセトン覚える
2CH2=CH2 + O2 → 2CH3CHO　（触媒：PdCl2・CuCl2）
(CH3COO)2Ca → CH3COCH3 + CaCO3　（乾留）

ホルムアルデヒドは刺激臭のある気体で、水に溶けやすい。約 37% の水溶液をホルマリンという。アセトアルデヒドは刺激臭のある液体で、工業的にはエチレンの酸化でつくる。アセトンは水と任意の割合で混じり合う液体で、溶媒に使う。実験室では酢酸カルシウムの乾留で得られ、工業的にはクメン法でフェノールといっしょにできる（フェノールの製法）。

エチレンの酸化の式は、反応の前後で原子の数を数えれば、触媒の名前を知らなくても生成物の分子式 C2H4O が決まる。2024 年本試験 第4問 問1 の決め手：「反応の前後で、原子の数は変わらない」。

ヨードホルム反応

ヨウ素と水酸化ナトリウム水溶液を加えて反応させると（温めることもある）、特有のにおいのあるヨードホルム CHI3 の黄色沈殿ができる。この反応が見ているのは、分子の中の決まった形である。

反応する2つの形場所を探す

CH3−CO−R または CH3−CH(OH)−R（R は H または炭化水素基）の形があれば、ヨードホルム反応を示す。2 つ目の形は、酸化されると 1 つ目の形になるアルコールの部分である。

示す示さない
エタノール・2-プロパノール・2-ブタノール（CH3−CH(OH)− の形）
アセトアルデヒド・アセトン（CH3−CO− の形）		メタノール・1-プロパノール（−OH のついた C の隣が CH3 でない）
酢酸（CH3−CO− の先が OH で、R にあたらない）

2026 年本試験 第4問 問2 の決め手：「ヨードホルム反応は、CH₃CO− か CH₃CH(OH)− の形」。条件がいくつも並ぶ構造決定では、構造式を見ただけで判定できるこの条件を先に当てると、選択肢を速く減らせる。

炭素が1つ減る数える
CH3COR + 3I2 + 4NaOH → CHI3 + RCOONa + 3NaI + 3H2O

CH3 の C が CHI3 として外れ、残りはカルボン酸の塩になる。もとの化合物より炭素数が 1 少ないカルボン酸の塩ができる。

カルボン酸

カルボキシ基 −COOH をもつ化合物で、アルデヒドを酸化すると得られる。水溶液中でわずかに電離して弱い酸性を示す。鎖式の 1 価のカルボン酸を脂肪酸といい、炭素数の多いものを高級脂肪酸という。

炭酸水素ナトリウムで二酸化炭素が出るか場所を探す
RCOOH + NaHCO3 → RCOONa + H2O + CO2

酸の強さは、塩酸・硫酸 ＞ スルホン酸 ＞ カルボン酸 ＞ 炭酸（CO2 の水溶液）＞ フェノール類 の順である。カルボン酸は炭酸より強いので、NaHCO3 から炭酸を追い出して CO2 が出る。フェノールは炭酸より弱いので、NaHCO3 とは反応しない。NaHCO3 で泡が出るかは、−COOH（またはスルホ基）があるかを見ている。

2025 年本試験 第4問 問1 の決め手：「弱い酸は、強い酸を追い出せない」。この問いの正答率は 55.2% だった。フェノールも酸なので CO2 が出る、と考えると誤りを見落とす作りである。

2つのカルボキシ基から水がとれる数える場所を探す
+脱水剤加熱

2 つの −COOH から H2O が 1 分子とれてできた化合物を酸無水物という。無水酢酸は −COOH をもたないので酸性を示さず、水と反応すると酢酸にもどる。1 分子の中で 2 つの −COOH が近くにあると、加熱するだけで酸無水物になる。マレイン酸は無水マレイン酸になるが、トランス形のフマル酸ではならない（シス-トランス異性体）。

覚えるカルボン酸覚える

ギ酸 HCOOH と酢酸 CH3COOH は刺激臭のある液体である。純度の高い酢酸は、室温が下がると固まるので氷酢酸ともいう。シュウ酸 (COOH)2 は最も簡単なジカルボン酸、アジピン酸 HOOC(CH2)4COOH はナイロン66 の原料、乳酸 CH3CH(OH)COOH は −OH をもつヒドロキシ酸である。

エステル

カルボン酸の −COOH とアルコールの −OH から水 1 分子がとれて結合した −COO− をエステル結合といい、この反応をエステル化という。エステル化は可逆反応で、濃硫酸を触媒にして加熱する。

とれる水は、酸の OH とアルコールの H場所を探す
+濃硫酸加熱+

酸素の同位体 18O を多く含むアルコールでエステル化すると、18O はエステルの方に入る。とれる水の O はカルボン酸の −OH から、H はアルコールの −OH からきている。

エステルの分子量は、足して水を引く数える

エステルの分子量 ＝ カルボン酸の分子量 ＋ アルコールの分子量 − 18 である。酢酸（60）とエタノール（46）からできる酢酸エチルは 60 ＋ 46 − 18 ＝ 88。逆に、付加反応のように何もとれない反応では、分子量は足し算のままになる。

2025 年本試験 第4問 問2 の決め手：「分子量の足し算で、付加か縮合かが分かる」。

加水分解とけん化場所を探す
CH3COOC2H5 + H2O ⇄ CH3COOH + C2H5OH　（酸を触媒にして加熱）
RCOOR′ + NaOH → RCOONa + R′OH　（けん化）

エステルに希塩酸や希硫酸を加えて加熱すると、エステル化の逆向きの反応が起こる（加水分解、可逆）。水酸化ナトリウムのような強塩基の水溶液で加熱すると、カルボン酸の塩とアルコールになる（けん化）。けん化は、酸を触媒にした加水分解とちがって不可逆である。セッケンの製造に使う。

エステルを2つに切って、もとの酸とアルコールを出す

  1. エステル結合 −CO−O− を探す。
  2. C＝O と O の間で切る。
  3. C＝O の側に OH をつけるとカルボン酸、O の側に H をつけるとアルコール。
  4. 両方の性質を、それぞれ確かめる。
STEP 1

エステル結合を探す

左から 2 番目の C に =O と −O− がついている。この組がエステル結合である。

STEP 2

2つに切る

C＝O の C と、その隣の O の間で切る。

STEP 3

OH と H をつける

C＝O の側に OH をつけるとギ酸、O の側に H をつけると 2-プロパノールになる。足した原子は H2O 1 分子分で、加水分解の式と合う。

STEP 4

両方を確かめる

ギ酸は還元性を示す（ギ酸）。2-プロパノールは第2級アルコールで、酸化するとアセトンになり、CH3−CH(OH)− の形をもつのでヨードホルム反応を示す。

間違えやすい所：片側だけで決めない場所を探す

エステルを手がかりにした構造決定では、条件が酸の側とアルコールの側の両方にかかっていることが多い。アルコールの側の条件だけを確かめて選ぶと、酸の側の条件を満たさないものを選んでしまう。2026 年本試験 第5問 問3a の決め手：「エステルは −CO−O− で2つに切る」。

エステルの性質覚える

分子量の小さいエステルは芳香のある液体で、水に溶けにくく、香料や溶媒に使う。果実の香りの多くはエステルによる。酢酸エチルは果実のようなにおいのある揮発性の液体で、水より軽い。硝酸や硫酸とアルコールから水がとれてできる化合物もエステルという。

油脂

3 価のアルコールであるグリセリン C3H5(OH)3 の 3 つの −OH と、高級脂肪酸の −COOH がエステル結合をつくった化合物を油脂という。

エステル結合は3つ数える
C3H5(OCOR)3 + 3NaOH → C3H5(OH)3 + 3RCOONa

油脂 1 分子にはエステル結合が 3 つあるので、油脂 1 mol をけん化するには NaOH（または KOH）が 3 mol 要る。できるのはグリセリンと、脂肪酸のナトリウム塩（セッケン）である。

油脂の分子式は、足して水を3つ引く数える

パルミチン酸 C15H31COOH（C16H32O2）1 分子とオレイン酸 C17H33COOH（C18H34O2）2 分子からなる油脂なら、グリセリン C3H8O3 と合わせて足し、エステル結合 3 つ分の H2O 3 分子を引く。

C3H8O3 ＋ C16H32O2 ＋ 2 × C18H34O2 − 3 × H2O ＝ C55H102O6

脂肪酸の二重結合を数える数える
脂肪酸示性式C＝C の数
パルミチン酸C15H31COOH0
ステアリン酸C17H35COOH0
オレイン酸C17H33COOH1
リノール酸C17H31COOH2
リノレン酸C17H29COOH3

炭化水素基 C17H35 は飽和で、C＝C が 1 つ増えるごとに H が 2 個減る。だから示性式の H を数えれば C＝C の数がわかり、名前を忘れても数えられる。上の油脂（パルミチン酸 1・オレイン酸 2）には C＝C が 2 つあるので、1 mol に H2 が 2 mol 付加する。

脂肪・脂肪油・硬化油覚える

飽和脂肪酸を多く含む油脂は常温で固体（脂肪）、不飽和脂肪酸を多く含む油脂は常温で液体（脂肪油）になりやすい。脂肪油にニッケルを触媒として水素を付加させると、常温で固体の油脂になる。これを硬化油といい、マーガリンやセッケンの原料に使う。

一定の質量の油脂をけん化するのに要する塩基の量からは油脂の分子量の大小が、一定の質量の油脂に付加するヨウ素の量からは C＝C の数の多少がわかる（教科書では「参考」として、けん化価・ヨウ素価という値で扱う）。

セッケン

油脂を水酸化ナトリウム水溶液でけん化して得られる高級脂肪酸のナトリウム塩 RCOONa をセッケンという。

水になじむ部分と油になじむ部分場所を探す

セッケンの陰イオン RCOO− は、炭化水素基 R の部分（疎水基）と −COO− の部分（親水基）からなる。水中では疎水基を内側に向けて集まり、ミセルというコロイド粒子をつくる。油に出会うと疎水基を油に向けて取り囲み、油を細かい粒にして水中に分散させる（乳化作用）。

セッケンの水溶液は弱い塩基性場所を探す
RCOO− + H2O ⇄ RCOOH + OH−イオン反応式

セッケンは弱酸（脂肪酸）と強塩基からなる塩なので、陰イオンの一部が水と反応して、水溶液は弱い塩基性を示す。

硬水や酸の中で泡立ちにくい場所を探す
2RCOO− + Ca2+ → (RCOO)2Caイオン反応式
RCOONa + HCl → RCOOH + NaCl

Ca2+ や Mg2+ を多く含む水（硬水）では、水に溶けにくい塩が沈殿する。強い酸性の水溶液では、弱酸である脂肪酸が遊離する。どちらでも RCOO− が減るので、洗浄作用が弱くなる。

合成洗剤覚える

硫酸ドデシルナトリウム C12H25OSO3Na やアルキルベンゼンスルホン酸ナトリウムは、強酸と強塩基からなる塩なので水溶液は中性で、カルシウム塩・マグネシウム塩も水に溶ける。そのため硬水や海水中でも使える。

検出反応は、どこを見ているか

酸素を含む化合物の検出反応を、見ている部分ごとにまとめる。構造決定では、この表の「見ている部分」を構造式の上で探す。芳香族の検出反応は芳香族化合物のページにある。

よく出る疑問

Q1ケトンは、なぜそれ以上酸化されないのか。

アルコールやアルデヒドの酸化では、C についた H がとれるか、C と H の間に O が入る。ケトンのカルボニル基の C には H が無く、2 つの炭化水素基と O だけがついているので、同じように酸化される場所が無い。

Q2酢酸は CH₃CO− の部分をもつのに、ヨードホルム反応を示さないのはなぜか。

反応する形は CH3−CO−R で、R は H か炭化水素基に限られる。酢酸では CH3−CO− の先が −OH なので、この形にあたらない。

Q3フェノールは酸なのに、炭酸水素ナトリウムと反応しないのはなぜか。

弱い酸の塩に、それより強い酸を加えたときだけ、弱い酸が遊離する。フェノールは炭酸より弱い酸なので、NaHCO3 から炭酸を追い出せない。逆に、ナトリウムフェノキシドの水溶液に CO2 を通すと、フェノールが遊離する。

Q4エステル化に濃硫酸を加えるのはなぜか。

触媒としてはたらき、反応を速くする。エステル化は可逆反応なので、加熱を続けても全部がエステルになるわけではない。

Q5アルデヒドを還元すると何になるか。

アルデヒドを還元すると第1級アルコール、ケトンを還元すると第2級アルコールにもどる。酸化の道すじを逆にたどった形である。
