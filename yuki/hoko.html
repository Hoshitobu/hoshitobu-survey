芳香族化合物

芳香族の反応では、ベンゼン環はたいてい残り、環についた基や H が置きかわる。試薬がどの基をねらうかを探し、置きかわる前後で原子を数える。

ベンゼンからの道すじ

芳香族の物質の多くは、ベンゼンから反応を1段ずつ重ねてつくる。どの段でも、ベンゼン環そのものは残り、環についた H や基が置きかわる。

プロペン触媒O2、H2SO4クメン法

先に要るもの：酸素を含む化合物

ベンゼンの構造

ベンゼン C6H6 は、6 個の C が正六角形の環をつくり、それぞれの C に H が 1 個ずつ結合した分子で、12 個の原子がすべて同一平面上にある。構造式は単結合と二重結合を交互に書く（ケクレ構造）が、実際の炭素原子間の距離は 6 つとも等しく、単結合と二重結合の中間である。

ベンゼンの性質覚える

無色で特有のにおいのある液体で、水に溶けにくく、水より軽い。炭素の割合が大きいので、空気中で燃やすと多量のすすを出す。ベンゼン環をもつ化合物を芳香族化合物という。

置換体の異性体を数える数える

ベンゼン環をもつ C8H10 は、環に置換基が 1 つ（エチル基）のものと、2 つ（メチル基 2 つ）のものに分かれる。二置換体は o-・m-・p- の 3 つあるので、合わせて 4 つである。数えるときは、置換基の数で分けてから位置を数える（o-・m-・p-）。

置換反応

数える

ベンゼン環は二重結合を書くが、構造が安定で付加反応を起こしにくく、H が他の原子や原子団と置きかわる置換反応を起こしやすい。置換反応では環が残り、とれた H は相手の原子といっしょに出ていく。

ハロゲン化
+Fe（または FeCl3）置換+

鉄粉または塩化鉄(Ⅲ)を触媒にして塩素と反応させると、H 1 個が Cl に置きかわり、とれた H は HCl として出ていく。分子式は C6H6 から C6H5Cl へ、H が 1 個減って Cl が 1 個増える。

ニトロ化
C6H6 + HNO3 → C6H5NO2 + H2O　（濃硫酸、約60℃）

濃硝酸と濃硫酸の混合物（混酸）で、H がニトロ基 −NO2 に置きかわる。とれた H は硝酸の OH といっしょに H2O になる。ニトロベンゼンは無色〜淡黄色の液体で、水に溶けにくく、水より重い。トルエンをニトロ化すると、おもに o- と p- のニトロトルエンができ、さらに進むと 2,4,6-トリニトロトルエン（TNT）になる。

スルホン化
C6H6 + H2SO4 → C6H5SO3H + H2O　（濃硫酸、加熱）

濃硫酸と加熱すると、H がスルホ基 −SO3H に置きかわってベンゼンスルホン酸になる。スルホン酸は水に溶けて強い酸性を示す。

付加反応と酸化

特別な条件では、ベンゼン環に付加反応や酸化が起こり、環の構造が失われる。置換と付加は、生成物の H の数を数えると見分けられる。

置換か付加かを数えて見分ける数える場所を探す
C6H6 + 3H2 → C6H12　（Pt または Ni 触媒、高圧）
C6H6 + 3Cl2 → C6H6Cl6　（光（紫外線））

水素を付加するとシクロヘキサン C6H12、紫外線を当てながら塩素を反応させると 1,2,3,4,5,6-ヘキサクロロシクロヘキサン C6H6Cl6 ができる。どちらも環に H や Cl が 6 個増えていて、何もとれていない。鉄を触媒にした塩素化（置換）では H が 1 個減り、HCl が出ていく。同じ塩素でも、触媒と光のどちらを使うかで反応の種類が変わる。

酸化されるのは側鎖場所を探す
KMnO4、H2SO4側鎖の酸化

ベンゼン環そのものは酸化されにくい。過マンガン酸カリウムで酸化されるのは、環についた炭化水素基（側鎖）である。酸化でできた安息香酸カリウムに硫酸を加えると、弱酸の安息香酸が遊離する。側鎖は、長さによらず環についた C が −COOH になる。トルエンでもエチルベンゼンでも安息香酸ができる。o-キシレンのように隣り合う 2 つの側鎖があれば、2 つの −COOH をもつフタル酸になる。

2025 年本試験 第5問 問3b の決め手：「酸化されるのは側鎖。環そのものはふつう残る」。

酸化バナジウム(Ⅴ)を触媒にした酸化覚える
2C6H6 + 9O2 → 2C4H2O3 + 4CO2 + 4H2O　（V2O5 触媒、高温）

酸化バナジウム(Ⅴ) V2O5 を触媒にして高温で酸素と反応させると、ベンゼン環そのものが酸化される。ベンゼンからは環の無い無水マレイン酸 C4H2O3 ができる。ナフタレンや o-キシレンを、触媒を使って高温で酸化すると、ベンゼン環が 1 つ残った無水フタル酸ができる。

間違えやすい所：触媒が同じでも、原料がちがえば生成物がちがう。2025 年本試験 第5問 問3b（ナフタレンの酸化）は正答率 49.1% で、ベンゼンの酸化でできる無水マレイン酸と取り違えた人がいたと考えられる。ナフタレンでは片方の環が開き、隣り合う 2 つの C に −COOH が残って、そこから H2O がとれる。

フェノール類

ベンゼン環の C に −OH が直接結合した化合物をフェノール類という。−OH が側鎖の C についたベンジルアルコール C6H5CH2OH はアルコールで、フェノール類ではない。

弱い酸としての性質場所を探す
C6H5OH ⇄ C6H5O− + H+イオン反応式
C6H5OH + NaOH → C6H5ONa + H2O
C6H5ONa + CO2 + H2O → C6H5OH + NaHCO3

フェノール類は、水溶液中でわずかに電離して弱い酸性を示し、NaOH 水溶液と中和して塩（ナトリウムフェノキシド）になって溶ける。アルコールは NaOH と反応しない。フェノールは炭酸より弱い酸なので、ナトリウムフェノキシドの水溶液に CO2 を通すとフェノールが遊離し、逆に NaHCO3 水溶液とは反応しない（酸の強さの順）。

塩化鉄(Ⅲ)で呈色する場所を探す

フェノール類の水溶液に塩化鉄(Ⅲ) FeCl3 水溶液を加えると、青紫〜赤紫色に呈色する。見ているのは、ベンゼン環に直接ついた −OH である。ベンジルアルコールや、−OH がエステルになったアセチルサリチル酸は呈色しない。

アルコールと同じ反応場所を探す
2C6H5OH + 2Na → 2C6H5ONa + H2
C6H5OH + (CH3CO)2O → C6H5OCOCH3 + CH3COOH

フェノールは、アルコールと同じように −OH で Na と反応して H2 を出し、無水酢酸と反応して酢酸エステル（酢酸フェニル）になる。−OH の H がアセチル基 CH3CO− に置きかわる反応をアセチル化という。

臭素水で白色沈殿数える場所を探す
3Br2臭素水

フェノールはベンゼンより置換反応を起こしやすい。臭素水を加えると、環の H 3 個が Br に置きかわった 2,4,6-トリブロモフェノールの白色沈殿ができ、HBr が 3 分子出ていく。フェノールの検出に使う。混酸でニトロ化すると、同じ 3 か所に −NO2 が入ったピクリン酸（2,4,6-トリニトロフェノール）になる。

アルコールフェノール類
Na との反応H2 が出る（−OH が −ONa になる）
無水酢酸との反応酢酸エステルができる
水溶液の性質中性弱い酸性
NaOH との反応反応しない中和して塩になる
FeCl3 水溶液呈色しない青紫〜赤紫色
クレゾールと異性体を数えて分ける数える場所を探す

ベンゼン環をもつ C7H8O は、−OH が環についたクレゾール（o-・m-・p- の 3 つ）、−OH が側鎖についたベンジルアルコール、O が環と CH3 の間に入ったメチルフェニルエーテル C6H5OCH3 の、合わせて 5 つである。Na と反応するのは −OH をもつ 4 つ、NaOH 水溶液に溶けて FeCl3 で呈色するのはクレゾールの 3 つ、どちらも示さないのはエーテルの 1 つになる。

フェノールの製法

どの製法も、最後にフェノールの塩から弱酸のフェノールを遊離させるか、別の物質といっしょに取り出す。それぞれの段で、環のどこが何に置きかわるかを追う。

クメン法数える覚える
C6H6 + CH2=CHCH3 → C6H5CH(CH3)2　（触媒）
C6H5CH(CH3)2 + O2 → C6H5C(CH3)2OOH
C6H5C(CH3)2OOH → C6H5OH + CH3COCH3　（硫酸で分解）

ベンゼンとプロペンからクメンをつくり、酸素で酸化してクメンヒドロペルオキシドにしたあと、硫酸で分解する。最後の式では、左の C 9 個・H 12 個・O 2 個が、フェノール（C 6・H 6・O 1）とアセトン（C 3・H 6・O 1）に分かれる。工業的なフェノールの製法で、アセトンも同時にできる。

アルカリ融解と、クロロベンゼンからの製法場所を探す

ベンゼンスルホン酸を NaOH で中和したベンゼンスルホン酸ナトリウムを、固体の NaOH と高温で融かす（アルカリ融解）と、−SO3Na の所が −ONa に置きかわってナトリウムフェノキシドになる。クロロベンゼンを NaOH 水溶液と高温・高圧で反応させると、−Cl の所が −ONa に置きかわる。どちらも、できたナトリウムフェノキシドに酸を加えるとフェノールが遊離する。

間違えやすい所：置きかわるのは、もとの基がついていた C だけである。−Cl や −SO3Na は環から外れ、生成物には残らない。2026 年本試験 第4問 問1 は、原料と試薬は正しく、生成物の構造だけがずらしてある反応式から正しいものを選ぶ問いで、正答率は 50.0% だった。反応の名前ではなく、どの場所が何に変わるかを構造式で確かめる。

芳香族カルボン酸とサリチル酸

ベンゼン環の C に −COOH が直接結合した化合物を芳香族カルボン酸という。水に溶けにくいが、水溶液中でわずかに電離して弱い酸性を示し、炭酸より強いので NaHCO3 と反応して CO2 を出す。

隣り合う2つのカルボキシ基場所を探す

フタル酸（o-）・イソフタル酸（m-）・テレフタル酸（p-）は互いに異性体である。フタル酸は 2 つの −COOH が隣り合っているので、加熱すると H2O がとれて無水フタル酸になる。テレフタル酸はポリエチレンテレフタラート（PET）の原料である。

サリチル酸の製法覚える
C6H5ONa + CO2 → C6H4(OH)COONa　（加熱・加圧）
2C6H4(OH)COONa + H2SO4 → 2C6H4(OH)COOH + Na2SO4

ナトリウムフェノキシドに二酸化炭素を加熱・加圧して反応させると、−ONa の隣（o- 位）に −COONa が入ってサリチル酸ナトリウムになる。硫酸を加えると、弱酸のサリチル酸が遊離する。サリチル酸は白色の結晶で、−COOH と −OH の両方をもつので、カルボン酸とフェノール類の両方の性質を示す。

試薬によってねらう基がちがう場所を探す
CH3OH濃硫酸、加熱
(CH3CO)2O濃硫酸

メタノールと濃硫酸では、−COOH がエステル化されてサリチル酸メチルになる（H2O がとれる）。無水酢酸では、−OH がアセチル化されてアセチルサリチル酸になる（酢酸が出ていく）。同じサリチル酸でも、反応する場所が逆である。

2026 年本試験 第4問 問1 の決め手：「無水酢酸は OH を、メタノールは COOH をねらう」。無水酢酸はアニリンの −NH2 もアセチル化する（アニリン）。

残った基で性質が決まる場所を探す
残っている基FeCl3 で呈色NaHCO3 で CO2用途
サリチル酸−OH・−COOHする（赤紫）出る医薬品（誘導体）の原料
サリチル酸メチル−OHする（赤紫）出ない消炎鎮痛剤（外用薬）
アセチルサリチル酸−COOHしない出る解熱鎮痛剤

アセチルサリチル酸をつくったあと、反応しなかったサリチル酸が残っているかは、FeCl3 水溶液で呈色するかで調べられる。サリチル酸メチルは水より重い油状の液体で、においがある。

アニリン

アンモニアの H を炭化水素基で置き換えた化合物をアミンといい、ベンゼン環に −NH2 が直接結合したものを芳香族アミンという。アニリン C6H5NH2 は最も簡単な芳香族アミンで、アンモニアと同じく弱い塩基である。

ニトロベンゼンの還元数える覚える
2C6H5NO2 + 3Sn + 14HCl → 2C6H5NH3Cl + 3SnCl4 + 4H2O
C6H5NH3Cl + NaOH → C6H5NH2 + NaCl + H2O

ニトロベンゼンをスズ（または鉄）と塩酸で還元すると、−NO2 が −NH2 になる。酸の中なので、まずアニリン塩酸塩 C6H5NH3Cl ができ、強塩基の NaOH を加えると弱塩基のアニリンが遊離する。工業的には、ニッケルなどの触媒で水素と反応させて還元する（C6H5NO2 + 3H2 → C6H5NH2 + 2H2O）。O 2 個が H2O として出ていき、N に H が 2 個つく。

アニリンの性質と検出場所を探す

アニリンは無色の油状の液体で、水にほとんど溶けないが、塩基なので塩酸には塩をつくってよく溶ける。酸化されやすく、空気中に置くと徐々に赤褐色になる。さらし粉水溶液で酸化すると赤紫色を呈する（検出に使う）。硫酸酸性の二クロム酸カリウム水溶液で酸化すると、水に溶けない黒色のアニリンブラックができる。

酸化されやすい基は、あとでつくる場所を探す

ベンゼン環に −NH2 と、酸化でつくる −COOH の両方をもたせたいとき、先に −NH2 にしてから過マンガン酸カリウムで側鎖を酸化すると、酸化されやすいアミノ基まで酸化されてしまう。そこで、側鎖の酸化を先に行い、−NO2 の還元をあとに行う。経路の問題では、1 段ごとに変わる場所を書き出し、順番の理由まで確かめる。

2024 年本試験 第4問 問4c の決め手：「酸化は先、還元はあと」。

アセチル化とアミド結合場所を探す
(CH3CO)2Oアセチル化

アニリンに無水酢酸を作用させると、−NH2 の H がアセチル基に置きかわってアセトアニリドができ、酢酸が出ていく。−NH−CO− の結合をアミド結合といい、アミド結合をもつ化合物をアミドという。アミド結合は、酸や塩基の水溶液と加熱すると加水分解される。

ジアゾ化とカップリング

アニリンから、窒素 2 個がつながった基を経て、色のついたアゾ化合物をつくる。温度と、窒素がどこで出ていくかが決め手になる。

ジアゾ化数える覚える
C6H5NH2 + NaNO2 + 2HCl → C6H5N2Cl + NaCl + 2H2O　（5℃以下）

アニリンの塩酸溶液を 5℃ 以下に冷やしながら亜硝酸ナトリウムを加えると、塩化ベンゼンジアゾニウム C6H5N2Cl（[C6H5−N≡N]+ Cl−）ができる。この反応をジアゾ化という。

温めると窒素が出ていく数える
C6H5N2Cl + H2O → C6H5OH + N2 + HCl　（5℃以上）

塩化ベンゼンジアゾニウムは分解しやすく、水溶液を温めると N2 が気体として出ていき、フェノールが残る。ジアゾ化を冷やして行うのは、この分解を防ぐためである。

ジアゾカップリング場所を探す
C6H5N2Cl + C6H5ONa → C6H5−N=N−C6H4OH + NaCl

塩化ベンゼンジアゾニウムの水溶液をナトリウムフェノキシドの水溶液に加えると、フェノールの p- 位で 2 つの環が −N=N− でつながり、橙赤色の p-ヒドロキシアゾベンゼンができる。−N=N− をアゾ基、アゾ基をもつ化合物をアゾ化合物といい、この反応をジアゾカップリングという。ジアゾ化で入った N 2 個は、分解では N2 として出ていき、カップリングでは分子の中に残る。

アゾ染料覚える

芳香族のアゾ化合物は黄色〜赤色の色素で、染料（アゾ染料）や顔料に使う。メチルオレンジやメチルレッドは、pH によって色が変わるので中和滴定の指示薬に使う。

経路を1段ずつ読む

経路の途中の物質を問う問題では、段ごとに「どこが何に変わったか」を書き出す。途中の1つだけを問われても、前後の段がわかれば決まる。

例：ベンゼンから p-ヒドロキシアゾベンゼンまで

  1. ニトロ化：環の H 1 個が −NO2 に置きかわる。
  2. 還元：−NO2 が −NH2 になる。
  3. ジアゾ化：−NH2 が −N2Cl になる（5℃ 以下）。
  4. カップリング：ナトリウムフェノキシドの p- 位とつながる。
STEP 1

ニトロ化

混酸で、H 1 個が −NO2 に置きかわる。とれた H は H2O になって出ていく。

STEP 2

還元

Sn と塩酸で還元し、NaOH で遊離させる。O 2 個が外れ、N に H 2 個がつく。

STEP 3

ジアゾ化

冷やしながら NaNO2 と塩酸を加える。−NH2 の N にもう 1 つの N がつながり、塩化ベンゼンジアゾニウムになる。ここで温めると N2 が出てフェノールになってしまう。

STEP 4

カップリング

ナトリウムフェノキシドの水溶液に加えると、2 つのベンゼン環がアゾ基でつながる。

分離とのつながり

フェノール類・カルボン酸は塩基と、アニリンは酸と反応して塩になり、水に溶けるようになる。塩になったものは水層に、塩にならないものはエーテル層に残る。どの水溶液でどれが塩になるかは、酸の強さの順（カルボン酸 ＞ 炭酸 ＞ フェノール類）とアニリンが塩基であることから決まる。分液ろうとを使った手順は、検出と分離のページで扱う。

よく出る疑問

Q1ベンゼンは二重結合を書くのに、付加より置換を起こしやすいのはなぜか。

ベンゼン環の構造は非常に安定で、炭素原子間の結合は単結合と二重結合の中間の状態にある。置換反応なら環の構造が保たれるので、置換反応の方が起こりやすい。付加反応は、高圧の水素と触媒や、紫外線のような特別な条件のときに起こる。

Q2ベンジルアルコールはフェノール類か。

フェノール類ではない。−OH がベンゼン環に直接ついておらず、−CH2− を挟んでいるので、アルコールの性質を示す。NaOH とは反応せず、FeCl3 でも呈色しない。Na とは反応する。

Q3アセチルサリチル酸は、なぜ塩化鉄(Ⅲ)で呈色しないのか。

呈色が見ているのはベンゼン環に直接ついた −OH である。アセチルサリチル酸では、この −OH がアセチル化されてエステル結合になっているので、呈色しない。サリチル酸メチルは −OH が残っているので呈色する。

Q4アニリンの検出に、さらし粉を使うのはなぜか。

アニリンは酸化されやすく、さらし粉で酸化されると赤紫色になる。ほかの芳香族化合物と区別できる、目で見える変化なので検出に使う。

Q5トルエンをニトロ化すると、どの位置に入るのか。

おもに o- 位と p- 位に入り、o-ニトロトルエンと p-ニトロトルエンができる。どの置換基のときにどの位置に入りやすいか（配向性）は、教科書では「思考学習」として扱われている。
