構造と異性体

構造式は、炭素の手が4本になるように原子をつないだものである。異性体は、つながり方を比べてから、二重結合と不斉炭素原子の場所を探して数える。

分子式・示性式・構造式・炭素の手は4本・異性体の分け方・構造異性体の数え方・シス-トランス異性体・不斉炭素原子と鏡像異性体・炭素の番号・分子の形・よく出る疑問・過去問で確かめる

先に要るもの：有機は「数える」と「場所を探す」で解ける

分子式・示性式・構造式

同じ分子を、何をどこまで書くかによって3通りに表す。分子式は原子の種類と数だけ、示性式は官能基を分けて書いた式、構造式は原子どうしの結合を線で書いた式である。構造式の C−H 結合や C−C 結合を省いて、示性式を線でつないだ形（簡略化した構造式）もよく使う。

分子式 C3H8O の化合物を例にとる。分子式は1つでも、つながり方のちがう3つの分子がある。

構造式から分子式にもどす数える

構造式の原子を種類ごとに数えると分子式になる。上の3つは、どれも C が 3 個、H が 8 個、O が 1 個で、分子式はすべて C3H8O である。示性式で書くと CH3CH2CH2OH・CH3CH(OH)CH3・CH3OC2H5 となり、官能基のちがいが見える。

官能基と化合物の名前覚える

官能基の名前と、それをもつ化合物の分類名は覚える。性質の多くは官能基で決まる。

官能基構造化合物の分類例

炭素の手は4本

原子が出す結合の数（価標の数）は元素で決まっている。C は 4 本、N は 3 本、O は 2 本、H と Cl は 1 本である。二重結合は 2 本、三重結合は 3 本と数える。

手の数で構造式を確かめる数える

エチレンの C は、C との二重結合で 2 本、H との単結合 2 本で、合わせて 4 本。アセチレンの C は、三重結合 3 本と H 1 本で 4 本。構造式を書いたら、どの C も 4 本になっているかを数えて確かめる。

アセチレンに H2 を 1 分子付加すると、三重結合のうち 1 本が開いて、それぞれの C に H が 1 個ずつ増える。C の手は 4 本のままなので、二重結合が 1 本残ってエチレンになる。

一般式と環・二重結合の数数える

鎖式で単結合だけの炭化水素（アルカン）は CnH2n+2。二重結合を 1 つもつ鎖式の炭化水素（アルケン）と、環を 1 つもつ炭化水素（シクロアルカン）は、どちらも CnH2n である。二重結合を 1 つ入れても環を 1 つ作っても、C どうしの結合が 1 本増えて、H が 2 個減るからである。三重結合を 1 つもつアルキンは CnH2n−2。

分子式の H がアルカンより何個少ないかを数えると、二重結合と環の数の合計がわかる。C4H8 なら H が 2 個少ないので、二重結合が 1 つか、環が 1 つある。

参考：不飽和度

教科書では「参考」として、この数え方に名前をつけている。C の数を n、H の数を m とすると（C・H・O だけの化合物）、不飽和度 ＝ (2n ＋ 2 − m) ÷ 2。二重結合（C＝O を含む）と環は 1 つにつき 1、三重結合は 2 と数える。中身は、上の「H がアルカンより何個少ないか」を 2 で割ったものと同じである。

異性体の分け方

分子式が同じで、構造がちがう化合物どうしを異性体という。原子のつながり方（結合の順序）がちがうものが構造異性体、つながり方は同じで空間での向きだけがちがうものが立体異性体である。立体異性体には、シス-トランス異性体と鏡像異性体がある。

つながり方を先に比べる場所を探す

2つの分子を見比べるときは、まず、どの原子がどの原子と結合しているかを順にたどる。つながり方がちがえば構造異性体。同じなら、二重結合のまわりの向き（シス-トランス）か、不斉炭素原子のまわりの向き（鏡像）を見る。

2025 年本試験 第4問 問3 の決め手：「つながり方が違えば構造異性体、同じで向きが違えば立体異性体」。

種類つながり方生じる場所例
構造異性体ちがう炭素の骨格・官能基の位置・官能基の種類1-プロパノールとエチルメチルエーテル
シス-トランス異性体同じ回転できない C＝C のまわりマレイン酸とフマル酸
鏡像異性体同じ不斉炭素原子のまわり乳酸の2つの形

構造異性体の数え方

数えもれと重なりを防ぐには、決まった順に書き出す。炭素の骨格 → 二重結合や官能基の位置 → 同じものを消す、の順である。

例：炭素 5 個のアルケン（分子式 C₅H₁₀ の鎖式化合物）

  1. 炭素の骨格を、主鎖の長いものから書き出す。
  2. それぞれの骨格に、二重結合を入れられる場所を全部入れる。
  3. 裏返したり回したりして重なるものを消す。
  4. 最後に、シス-トランス異性体があるものを探す。
STEP 1

骨格を書き出す

炭素 5 個の骨格は、5 個の直鎖、4 個の主鎖に枝 1 本、3 個の主鎖に枝 2 本、の 3 通りである。

STEP 2

二重結合を入れる

C＝C は、隣り合う 2 つの C がどちらも H をもつ所にだけ入る。枝が 2 本の骨格は、真ん中の C に H が無いので、二重結合を入れられない。

STEP 3

重なりを消す

直鎖の右端に入れた二重結合は、左右を裏返すと 1-ペンテンと同じ、右から 2 番目に入れたものは 2-ペンテンと同じである。番号は小さくなる側から数える。構造異性体は上の 5 つになる。

STEP 4

シス-トランス異性体を探す

C＝C の両方の C に、それぞれちがう 2 つの原子・基がついているのは 2-ペンテンだけである（次の節）。2-ペンテンにはシス形とトランス形があるので、立体異性体まで区別すると全部で 6 つになる。

間違えやすい所：何の数を聞かれているか数える場所を探す

同じ分子式について、「構造異性体の数」「立体異性体まで区別した異性体の数」「立体異性体が存在する構造異性体の数」は、それぞれちがう数になる。上の例では順に 5、6、1 である。シス形とトランス形の 2 つを数えるのか、それをもつ構造異性体の 1 つを数えるのかを、問いの文から読み分ける。

2026 年本試験 第4問 問3 の決め手：「数えるのは『構造異性体』の方」。2問目の正答率は 47.9% で、この大問でもっとも低かった。シス形とトランス形の 2 つを数えて答えた人が多かったと考えられる。

官能基の種類から分ける数える場所を探す

O を含む分子式では、まず官能基の種類で分ける。C3H8O（H が C3H8 と同じなので、二重結合も環も無い）なら、O を C と H の間に入れるとアルコール、C と C の間に入れるとエーテルになる。アルコールは −OH の位置で 2 つ（1-プロパノール・2-プロパノール）、エーテルは 1 つ（エチルメチルエーテル）で、合わせて 3 つである。

このうち単体のナトリウムと反応して H2 を出すのは、−OH をもつアルコールの 2 つだけである（アルコール）。異性体を数えたあとに、反応する場所をもつものを探す問いが多い。

シス-トランス異性体

C＝C は、C−C 単結合とちがって、結合を軸にして回転できない。そのため、C＝C の両側の C についた原子・基の並び方が固定され、同じ側にあるもの（シス形）と反対側にあるもの（トランス形）が別の物質になる。

二重結合の両端を見る場所を探す

C＝C の左の C には CH3 と H、右の C には C2H5 と H がついている。どちらの C にも、ちがう 2 つがついているので、シス-トランス異性体がある。

どちらか一方の C に同じものが 2 つついていると、シス-トランス異性体は無い。1-ペンテンの端の =CH2、2-メチル-2-ブテンの CH3 が 2 つついた C がその例である。

マレイン酸とフマル酸場所を探す

どちらも HOOC−CH=CH−COOH で、つながり方は同じである。マレイン酸は 2 つの −COOH が同じ側にあり近いので、加熱すると水 1 分子がとれて無水マレイン酸になる。フマル酸は −COOH が離れていて、この反応は起こらない（カルボン酸）。

不斉炭素原子と鏡像異性体

4 本の手に、4 つともちがう原子・基が結合した炭素原子を不斉炭素原子という。不斉炭素原子を 1 個もつ分子には、実物と鏡に映した像の関係にある 2 つの分子があり、互いに重ね合わせることができない。これを鏡像異性体という。

4つともちがうかを確かめる場所を探す

乳酸の * の C には、H・CH3・OH・COOH の 4 つ、2-ブタノールの * の C には、H・CH3・OH・C2H5 の 4 つがついている。CH3 と C2H5 はちがう基として数える。

2-プロパノール CH3CH(OH)CH3 の中央の C は、CH3 が 2 つついているので不斉炭素原子ではない。H を 2 つもつ C（−CH2−）や、二重結合の C も不斉炭素原子にはならない。

鏡像異性体の性質覚える

鏡像異性体どうしは、融点・沸点・密度などの性質がほとんど同じで、光に対する性質や、味・においなどの生体へのはたらきがちがう。

反応のあとに不斉炭素原子ができるか場所を探す

付加反応で H や基が増えると、それまで同じものが 2 つついていた C や、二重結合の C が、4 つともちがう C に変わることがある。反応の前後の構造式を書き、反応した C のまわりの 4 つを並べて確かめる。構造決定の条件にも「不斉炭素原子をもつ／もたない」がよく使われる。

炭素の番号

数える

官能基や枝の位置は、炭素の番号で表す。番号のつけ方を知っていると、名前から構造式を書け、構造式の大きさ（環の原子の数など）を数えられる。

主鎖の番号

主鎖の端から番号をつけ、官能基・二重結合・枝の番号が小さくなる側から数える。1-プロパノールは 1 番の C に、2-プロパノールは 2 番の C に −OH がある。

ベンゼン環の o-・m-・p-

ベンゼン環に置換基が 2 つあるとき、隣り合う位置をオルト（o-）、1 つおいた位置をメタ（m-）、向かい合う位置をパラ（p-）という。二置換体は、置換基の種類が同じでも 3 つの異性体がある。

カルボキシ基の隣から数えるα・β

−COOH がついた炭素を α 位、その次の炭素を β 位、以下 γ・δ・ε と数える。α-アミノ酸は、−NH2 と −COOH が同じ炭素についたアミノ酸である。

分子の中で −NH2 と −COOH がアミド結合をつくって環になると、環の原子は、N と、N がついた炭素から α 位までの炭素と、カルボキシ基の C である。β 位の N なら、N・β 位の C・α 位の C・C＝O の C で、環の原子は 4 個（四員環）。ε 位（5 番目）の N なら、N・ε〜α 位の C 5 個・C＝O の C で 7 個になる。ナイロン6 の原料のカプロラクタムの環がこの形である。

2024 年本試験 第4問 問4b の決め手：「β は COOH から2番目の炭素。N がそこにつくと四員環」。

分子の形

単結合のまわりは自由に回転できるが、二重結合・三重結合のまわりは回転できない。結合の種類が決まると、まわりの原子の並び方が決まる。

二重結合と三重結合のまわりの原子場所を探す

C＝C の 2 つの C と、それに直接結合した 4 つの原子の、合わせて 6 個は、いつも同一平面上にある。エチレンはすべての原子が同一平面上にある。2-メチルプロペンでは、C＝C の 2 つの C、端の H 2 個、CH3 の C 2 個の 6 個が同一平面上にあるが、CH3 の H は単結合のまわりで回転するので、いつも同じ平面にあるとは限らない。

C≡C の 2 つの C と、それに直接結合した 2 つの原子の 4 個は、いつも一直線上にある。アセチレンは直線形の分子である。

ベンゼンは 6 個の C と 6 個の H の 12 個が同一平面上にある正六角形の分子である（芳香族化合物）。

炭素原子間の距離覚える

炭素原子間の距離は、単結合 ＞ ベンゼンの炭素原子間 ＞ 二重結合 ＞ 三重結合 の順に短くなる。ベンゼンの 6 つの炭素原子間の距離はすべて等しく、単結合と二重結合の中間である。

よく出る疑問

Q1シクロアルカンとアルケンは異性体なのか。

炭素の数が同じなら、どちらも CnH2n なので、互いに構造異性体である。問いが「アルケンの異性体」なら環の形は数えない。分子式だけを与えて「異性体」と言うときは、環の形も含まれる。

Q2シス形とトランス形は、性質も同じなのか。

つながり方は同じでも、別の物質なので性質はちがう。マレイン酸（シス形）とフマル酸（トランス形）は融点が大きくちがい、加熱すると酸無水物になるのはマレイン酸だけである。

Q3構造式の向きや折れ曲がりがちがうと、別の物質になるのか。

単結合のまわりは回転できるので、鎖を曲げて書いても、左右を裏返して書いても、つながり方が同じなら同じ物質である。別の物質になるのは、つながり方がちがうとき、C＝C のまわりの並び方がちがうとき、不斉炭素原子のまわりの向きがちがうとき、の3つである。

Q4エタノールとジメチルエーテルの沸点が大きくちがうのはなぜか。

どちらも C2H6O の構造異性体だが、エタノールは −OH をもち、分子間で水素結合をつくる。ジメチルエーテルは −OH をもたないので水素結合をつくれず、沸点がずっと低い。
