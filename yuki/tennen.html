天然高分子

天然高分子は、単糖・アミノ酸・ヌクレオチドが水をとりながらつながったものである。糖の還元性は環が開けるかで、タンパク質の検出反応は分子のどの部分があるかで、電気泳動の向きは pH と等電点の大小で決まる。

天然高分子は、水をとってつながる

糖類・タンパク質・核酸は、小さな単位が脱水縮合でつながった天然高分子である。つながった結合は、酸や酵素で加水分解すると、もとの単位にもどる。

高分子単位つなぐ結合例
多糖単糖（グルコースなど）グリコシド結合 C−O−Cデンプン・グリコーゲン・セルロース
タンパク質α-アミノ酸ペプチド結合 −CO−NH−アルブミン・ケラチン・酵素
核酸ヌクレオチド糖の −OH とリン酸の −OH の脱水縮合DNA・RNA

単位が 1 つつながるたびに H2O が 1 分子とれる。分子量や質量の計算では、この水を数える。

先に要るもの：銀鏡反応、鏡像異性体、合成高分子

単糖

ホルミル基 −CHO またはカルボニル基 −CO− と、2 つ以上のヒドロキシ基 −OH をもつ化合物を糖類という。分子式が Cm(H2O)n の形のものが多く、炭水化物ともいう。最小の単位を単糖、2 つがつながったものを二糖、多数がつながったものを多糖という。

グルコースは、水の中で3つの形をとる場所を探す

グルコース（ブドウ糖）C6H12O6 は、結晶中ではおもに O 原子 1 個と C 原子 5 個が環になった六員環の構造をとる。水溶液中では、環状の α-グルコース、環が開いた鎖状構造、環状の β-グルコースの 3 種類が平衡状態にある。鎖状構造には −CHO があるので、グルコースの水溶液は還元性を示し、銀鏡反応を起こし、フェーリング液を還元する。

環が開くのは、1 番の C の所である。環状構造の 1 番の C には、環の O と −OH の両方が結合している。この形をヘミアセタール構造といい、ここで環が開いて −CHO ができる。α 形と β 形は、1 番の C についた −OH の向きだけがちがう立体異性体である。

間違えやすい所：グルコースは 2 種類ではなく 3 種類場所を探す

2025 年本試験 第4問 問3 は、天然の化合物の記述から誤りを 1 つ選ぶ問いで、正答率は 43.3% だった。解説動画では、グルコースを α と β の 2 種類と覚えていた人が、「環状 2 種類と鎖状 1 種類の合計 3 種類」という正しい記述を誤りにしたと推測している。誤りは、フルクトースをグルコースの立体異性体とした記述だった。

2025 年本試験 第4問 問3 の決め手：「つながり方が違えば構造異性体、同じで向きが違えば立体異性体」。グルコースとフルクトースは、鎖状構造で C=O の位置（1 番の C か 2 番の C か）がちがうので、構造異性体である。α-グルコースと β-グルコースは、つながり方が同じで向きがちがうので立体異性体である（異性体の分け方）。

フルクトースも還元性を示す場所を探す

フルクトース（果糖）C6H12O6 は、糖類の中で最も甘味が強く、果実やはちみつに含まれる。水溶液中では、六員環・五員環の環状構造と鎖状構造が平衡状態にある。鎖状構造にホルミル基は無く、2 番の C がケトンの形になっているが、−CO−CH2OH の部分が酸化されやすいので、水溶液は還元性を示す。鎖状構造がアルデヒドの単糖（グルコースなど）をアルドース、ケトンの単糖（フルクトース）をケトースという。

ガラクトースはラクトース（乳糖）の構成成分で、水溶液中で鎖状構造をとってホルミル基をもつので、還元性を示す。

アルコール発酵数える覚える
C6H12O6 → 2C2H5OH + 2CO2

グルコースやフルクトースは、酵母のもつ酵素のはたらきで、エタノールと二酸化炭素になる（アルコール発酵）。C 6 個が、エタノール 2 分子（C 4 個）と CO2 2 分子（C 2 個）に分かれる。

二糖

2 つの単糖が脱水縮合でつながった糖を二糖という。単糖のヘミアセタール構造の C についた −OH と、別の単糖の −OH から H2O がとれてできる C−O−C の結合をグリコシド結合という。分子式はどれも C6H12O6 × 2 − H2O ＝ C12H22O11 である。

還元性は、環が開けるかで決まる場所を探す
二糖できている単糖とつながる C還元性加水分解する酵素
マルトース（麦芽糖）α-グルコースの 1 番 ＋ グルコースの 4 番示すマルターゼ
セロビオースβ-グルコースの 1 番 ＋ グルコースの 4 番示すセロビアーゼ
ラクトース（乳糖）β-ガラクトースの 1 番 ＋ グルコースの 4 番示すラクターゼ
スクロース（ショ糖）α-グルコースの 1 番 ＋ β-フルクトースの 2 番示さないインベルターゼ（スクラーゼ）

マルトース・セロビオース・ラクトースは、一方の単糖の 1 番の C がグリコシド結合に使われていても、もう一方の単糖のヘミアセタール構造が残っている。そこで環が開くので還元性を示す。スクロースは、グルコースの 1 番の C とフルクトースの 2 番の C、つまり環が開くはずの所どうしでつながっているので、どちらの環も開けず、還元性を示さない。

2024 年本試験 第4問 問4a の決め手：「1位の C がふさがると、鎖状の形になれない」。解説動画では、「グルコースが入っているかでなく、開けるか」と説明している。

間違えやすい所：グルコースを含んでいても、還元性があるとは限らない場所を探す

2024 年本試験 第4問 問4a（正答率 55.5%）は、グルコースの 1 番の C が別の分子とグリコシド結合でつながった、教科書に無い化合物を題材にした。グルコースを含むから銀鏡反応を示す、と考えると誤りを見落とす作りである。開くはずの 1 番の C がふさがっていないかを、構造式の上で確かめる。

スクロースの転化数える場所を探す
C12H22O11 + H2O → C6H12O6 + C6H12O6

スクロースに希酸を加えて加熱するか、インベルターゼを作用させると、グルコースとフルクトースの等量混合物になる。この反応を転化、できた混合物を転化糖という。グルコースもフルクトースも還元性を示すので、転化糖は還元性を示す。スクロースはサトウキビやテンサイに含まれ、砂糖の主成分である。マルトースは水あめの主成分で、デンプンにアミラーゼを作用させて得る。

参考：トレハロース

教科書では「参考」として、2 つの α-グルコースが 1 番の C どうしでつながった二糖のトレハロースを紹介している。環が開くはずの所どうしでつながっているので、スクロースと同じく還元性を示さない。2026 年本試験 第4問 問4（正答率 58.3%）にはこの物質が選択肢に出たが、記述は正しく、誤りはアミロースを β-グルコースからなるとした記述だった。解説動画では、見なれないトレハロースに引っぱられた人がいたと推測している。

多糖

多数の単糖が縮合重合でつながった糖を多糖といい、分子量は 104〜107 程度と大きい。水に溶けにくいものが多く、甘味が無く、還元性も示さない。デンプン・グリコーゲン・セルロースは、どれも分子式 (C6H10O5)n で表され、グルコースだけからできている。ちがいは、α か β か、枝分かれがあるかである。

アミロースは直鎖、アミロペクチンは枝分かれ場所を探す
アミロースアミロペクチン
つながり方α-グルコースの 1 番と 4 番の C の間だけ（直鎖状）1 番と 4 番のほかに、1 番と 6 番の C の間でもつながる（枝分かれ）
水への溶け方冷水には溶けにくく、熱水に溶ける熱水にも溶けにくい
ヨウ素デンプン反応濃青色赤紫色
分子量のめやす104〜105106〜107

デンプンは植物がグルコースを貯える形で、アミロースとアミロペクチンからなる。うるち米のデンプンはアミロースが 20〜25%、アミロペクチンが 75〜80% だが、もち米のデンプンはほぼ 100% がアミロペクチンである。鎖状の部分は α-グルコース約 6 分子で 1 回転するらせん構造で、−OH どうしの水素結合で保たれている。このらせんにヨウ素が取りこまれると呈色する（ヨウ素デンプン反応）。呈色した溶液を加熱すると色が消え、冷やすと再び呈色する。

2024 年本試験 第4問 問2 の決め手：「アミロースは直鎖、アミロペクチンは枝分かれ」。この問い（正答率 76.6%）の誤りは、アミロペクチンが冷水に溶けやすいとした記述だった。

デンプンの加水分解数える

(C6H10O5)n ＋ n H2O → n C6H12O6

デンプンに希酸を加えて加熱すると、最終的にグルコースになる。アミラーゼを作用させるとマルトースになり、マルトースはマルターゼでグルコースになる。途中で止めると、デンプンより分子量の小さいデキストリンができ、加水分解が進むにつれて、ヨウ素デンプン反応の色は紫色から赤、褐色を経てしだいに薄くなる。

くり返し単位 C6H10O5 の式量は 162、グルコースは 180 で、1 単位につき H2O 1 分子（18）が加わる。デンプン 81 g（単位 0.50 mol）をすべて加水分解すると、グルコースは 0.50 mol、90 g になる。

グリコーゲン覚える

グリコーゲンは動物の肝臓や筋肉に含まれ、動物がグルコースを貯える形である（動物デンプン）。α-グルコースがつながった構造で、アミロペクチンよりさらに枝分かれが多く、分子の形は球状になる。水に溶け、還元性は示さない。ヨウ素デンプン反応では赤褐色になる。

デンプンは α、セルロースは β場所を探す

セルロースは植物の細胞壁の主成分で、多数の β-グルコースが 1 番と 4 番の C の間でつながった直線状の分子である。β-グルコースは交互に向きを変えてつながるので、らせん構造をつくらず、ヨウ素デンプン反応を示さない。直線状の分子どうしが水素結合で強く結びつくので繊維になり、熱水や有機溶媒に溶けにくい。還元性は示さない。

希酸を加えて長時間煮沸すると、徐々に加水分解されてグルコースになる。セルラーゼを作用させるとセロビオースになる。

2026 年本試験 第4問 問4 の決め手：「デンプンは α、セルロースは β」。解説動画では、糖で聞かれるのは「何からできているか・還元性があるか・ヨウ素で何色になるか」の 3 つで、還元性は −CHO が出られるかで決まると説明している。糖の還元性も、アルデヒドの銀鏡反応と同じしくみである（銀鏡反応）。

セルロースの利用

セルロースのくり返し単位には −OH が 3 つあるので、化学式を [C6H7O2(OH)3]n と書く。この −OH を変化させたり、溶かして形を変えたりして、繊維をつくる。

アセテート：−OH を酢酸エステルにする（半合成繊維）数える場所を探す

[C6H7O2(OH)3]n ＋ 3n (CH3CO)2O → [C6H7O2(OCOCH3)3]n ＋ 3n CH3COOH

セルロースを無水酢酸と（酢酸と硫酸の存在下で）反応させると、3 つの −OH がすべてアセチル化されてトリアセチルセルロースになる。これは溶媒に溶けにくいので、エステル結合の一部を加水分解してジアセチルセルロースにし、アセトンに溶かして細い穴から押し出し、アセトンを蒸発させて繊維にする。これをアセテートといい、天然のセルロースの構造の一部を化学的に変えた繊維なので半合成繊維とよぶ。

くり返し単位の式量は、セルロース 162 から、−OH 1 つが −OCOCH3 に変わるたびに 42 増える。トリアセチルセルロースでは 162 ＋ 3 × 42 ＝ 288 である。

ニトロセルロースは、硝酸エステル場所を探す

セルロースに濃硝酸と濃硫酸の混合物（混酸）を作用させると、−OH が硝酸とエステルをつくり、ニトロセルロースになる。名前に「ニトロ」とつくが、−NO2 が C に直接ついたニトロ化合物ではなく、C−O−NO2 の形の硝酸エステルである。

レーヨン：溶かして、もどす（再生繊維）覚える

水酸化銅(Ⅱ)を濃アンモニア水に溶かした溶液（シュバイツァー試薬）にセルロースを溶かし、希硫酸の中に細い穴から押し出すと、再びセルロースにもどる。この繊維を銅アンモニアレーヨン（キュプラ）という。セルロースを水酸化ナトリウム水溶液と二硫化炭素 CS2 で処理し、薄い NaOH 水溶液に溶かしたものをビスコースといい、希硫酸の中に押し出すとセルロースにもどってビスコースレーヨンになる。細いすき間から膜状に押し出すとセロハンになる。短いセルロースを長い繊維に再生したものなので、再生繊維とよぶ。

アミノ酸

分子中にアミノ基 −NH2 とカルボキシ基 −COOH をもつ化合物をアミノ酸という。2 つが同じ C に結合したものを α-アミノ酸といい、タンパク質をつくるおもなアミノ酸は約 20 種類ある。

側鎖 R で性質が決まる場所を探す
アミノ酸側鎖 R特徴
グリシンH最も簡単。不斉炭素原子が無く、鏡像異性体が無い
アラニンCH3鏡像異性体がある
フェニルアラニン・チロシンベンゼン環を含むキサントプロテイン反応で見つかる
システイン・メチオニンS を含む硫黄の検出で見つかる。システインの −SH どうしは −S−S− をつくる
グルタミン酸−COOH を含む酸性アミノ酸
リシン−NH2 を含む塩基性アミノ酸

グリシン以外の α-アミノ酸は不斉炭素原子をもつので、鏡像異性体がある（鏡像異性体）。天然のものの多くは片方の形だが、その表し方（D 形・L 形）は教科書では「発展」として扱う。

双性イオンだから、融点が高い場所を探す

結晶中や水溶液中では、−COOH の H+ が −NH2 に移り、−NH3+ と −COO− をもつ形になっている。正と負の電荷を両方もち、全体として電荷が 0 のイオンを双性イオンという。結晶は、双性イオンどうしが静電気力で引き合うイオン結晶に近いので、アミノ酸の融点は有機化合物としては高い（多くは融点に達する前に分解する）。水には溶けやすく、ジエチルエーテルなどの有機溶媒には溶けにくい。

等電点より酸性側は陰極へ、塩基性側は陽極へ場所を探す
H3N+−CH(R)−COOH ⇄ H3N+−CH(R)−COO− ⇄ H2N−CH(R)−COO−イオン反応式

水溶液中のアミノ酸は、陽イオン・双性イオン・陰イオンが平衡にある。酸性の水溶液では −COO− が H+ を受け取って、ほとんどが陽イオン（左）になる。塩基性の水溶液では −NH3+ が H+ を放して、ほとんどが陰イオン（右）になる。

アミノ酸の水溶液に直流電圧をかけると、陽イオンは陰極へ、陰イオンは陽極へ移動する（電気泳動）。全体の電荷が 0 になってどちらにも移動しない pH を等電点という。等電点より pH が低ければ陰極へ、高ければ陽極へ動く。等電点は、グリシン 5.97、アラニン 6.00 のような中性アミノ酸はおよそ 6、酸性アミノ酸のグルタミン酸は 3.22、塩基性アミノ酸のリシンは 9.74 である。pH 6 で電気泳動すれば、グルタミン酸は陽極へ、リシンは陰極へ動き、グリシンはほとんど動かない。

2026 年本試験 第4問 問5b の決め手：「等電点より酸性側は陰極へ、塩基性側は陽極へ」。解説動画では、コロイド粒子の電気泳動と同じで、電荷の符号で動く向きが決まると説明している。滴定の途中でグリシンがどの形かを問うこの問い（正答率 67.3〜70.5%）は、pH が低いか高いかだけで決まる。各点の pH を計算で出すこと（アミノ酸の電離平衡と pH）は、教科書では「参考」として扱う。

アミノ酸の反応と、ニンヒドリン反応場所を探す

アミノ酸は −COOH をもつので、アルコールと反応してエステルになる。−NH2 をもつので、無水酢酸などのカルボン酸無水物と反応してアミドになる（アニリンのアセチル化と同じ）。アミノ酸の水溶液にニンヒドリン水溶液を加えて温めると、−NH2 がニンヒドリンと反応して赤紫〜青紫色になる（ニンヒドリン反応）。

ペプチドとタンパク質

アミノ酸の −COOH と別のアミノ酸の −NH2 から H2O がとれてできるアミド結合を、特にペプチド結合という。2 分子がつながったものをジペプチド、3 分子をトリペプチド、多数がつながったものをポリペプチドという。

−CO−NH− だけを数える数える

アミノ酸が n 個つながったペプチドには、ペプチド結合が n − 1 個あり、H2O が n − 1 分子とれている。グリシン（分子量 75）とアラニン（89）からなるジペプチドの分子量は 75 ＋ 89 − 18 ＝ 146。2 種類のアミノ酸を 1 つずつ使うジペプチドには、どちらの −COOH がペプチド結合に使われるかで 2 通りの構造異性体がある。

ペプチド結合は、C＝O の隣に N−H が来ている所である。末端のカルボキシ基にも C＝O があるが、隣は −OH なのでペプチド結合ではない。2026 年本試験 第4問 問5a（正答率 58.4%）について、解説動画では、カルボキシ基の C＝O まで数えた人がいたと推測している。解説動画のこの場面の題は「−CO−NH− だけを数える」。

一次構造から四次構造まで場所を探す

タンパク質は、おもにポリペプチドからなり特定の立体構造をもつ高分子で、分子量は 104〜106 程度である。性質は、アミノ酸の種類と数だけでなく、並ぶ順番と立体構造で変わる。

構造中身保っているもの・例
一次構造アミノ酸の配列順序ペプチド結合
二次構造α-ヘリックス（らせん）・β-シート（ひだ状の平面）ペプチド結合の C＝O と N−H の間の水素結合
三次構造二次構造がさらに折れ曲がった、特定の立体構造側鎖どうしのイオン結合や、ジスルフィド結合 −S−S−（2 か所のシステインの −SH が酸化されてできる）など
四次構造三次構造をもつ複数のポリペプチド鎖（サブユニット）の組み合わせ例：ヘモグロビン

α-アミノ酸だけからなるものを単純タンパク質、糖・リン酸・色素なども含むものを複合タンパク質という。形で分けると、水に溶けやすい球状タンパク質（アルブミン・グロブリンなど）と、水に溶けにくい繊維状タンパク質（ケラチン・コラーゲン・フィブロインなど）がある。

塩析・変性・加水分解場所を探す

水溶性のタンパク質は、水中で親水コロイドになる。多量の電解質を加えると、水和している水分子が奪われて沈殿する（塩析）。熱・酸・塩基・重金属イオン（Cu2+・Hg2+・Pb2+ など）・有機溶媒などを加えると、立体構造が変わって凝固や沈殿が起こり、特有の性質や機能が失われる（タンパク質の変性）。生卵を加熱すると固まるのは変性である。一次構造がそのままでも、高次構造を保つ水素結合やイオン結合が失われると、もとにはもどらないことが多い。酸や酵素で加水分解すると、α-アミノ酸になる。

タンパク質の検出反応

タンパク質やペプチドの検出反応は、それぞれ分子の決まった部分を見ている。構造式があれば、その部分があるかを探すだけで判定できる。

検出反応が見ている部分場所を探す
反応操作見ている部分結果

キサントプロテイン反応濃硝酸を加えて加熱し、冷やしてからアンモニア水で塩基性にするベンゼン環（ニトロ化される）黄色、塩基性で橙黄色

ビウレット反応は、ペプチド結合の部分が Cu2+ と錯イオンをつくって起こる。キサントプロテイン反応は、チロシンやフェニルアラニンのベンゼン環がニトロ化されて起こる。

2024 年本試験 第4問 問3 の決め手：「検出反応は、分子の決まった部分を見ている」。

間違えやすい所：ビウレット反応はタンパク質だけの反応ではない場所を探す

2024 年本試験 第4問 問3 は、構造式で示したトリペプチドに 3 つの検出反応を行い、変化が見られるものをすべて選ぶ問いで、正答率は 46.5% だった。ベンゼン環・アミノ基・2 つのペプチド結合を構造式の上で探せば、どれも起こると判定できる。解説動画では、ビウレット反応をタンパク質だけの反応と覚えていた人が、トリペプチドでは起こらないとしたと推測している。アミノ酸 1 つやジペプチドではビウレット反応は起こらないが、トリペプチド以上なら起こる。

酵素

生体内の化学反応で触媒としてはたらくタンパク質を酵素という。酵素が作用する物質を基質といい、基質は酵素の活性部位（活性中心）に結合して酵素-基質複合体になり、生成物ができると酵素はもとにもどる。

基質特異性と、最適温度・最適 pH場所を探す

活性部位は特定の立体構造をもつので、酵素は特定の基質にしか作用しない（基質特異性）。たとえばアミラーゼはデンプンの加水分解にだけ触媒としてはたらく。

酵素はタンパク質なので、温度が高すぎると変性してはたらきを失う（失活）。反応速度が最も大きくなる温度（最適温度）は、多くの酵素で 35〜40℃ 付近である。はたらきは pH によっても変わり、最も大きくなる pH（最適 pH）は多くの酵素で中性付近（5〜8）だが、胃液のペプシンのように 2 付近のものもある。無機物質の触媒では、温度が高いほど反応速度が大きくなるのとちがう。

セロビアーゼセロビオース → グルコース

酵素の名前は、糖の名前の語尾「オース（-ose）」を「アーゼ（-ase）」にしたものが多い。

核酸

核酸は、遺伝に深くかかわる高分子化合物で、DNA（デオキシリボ核酸）と RNA（リボ核酸）がある。単位はヌクレオチドで、リン酸・糖・塩基が脱水縮合でつながった分子である。ヌクレオチドの糖の −OH と、別のヌクレオチドのリン酸の −OH が脱水縮合して、鎖状のポリヌクレオチドになる。

DNA と RNA は、糖と塩基 1 つがちがう場所を探す
DNARNA
糖デオキシリボース C5H10O4リボース C5H10O5
塩基アデニン（A）・グアニン（G）・シトシン（C）・チミン（T）アデニン（A）・グアニン（G）・シトシン（C）・ウラシル（U）
形2 本の鎖の二重らせん構造1 本の鎖

デオキシリボースはリボースより O 原子が 1 個少ない。DNA は、2 本のポリヌクレオチド鎖の塩基どうしが水素結合で対をつくって、二重らせん構造をとる。対になるのは A と T、G と C で、A と T の間には 2 つ、G と C の間には 3 つの水素結合ができる。RNA にはおもに mRNA（伝令 RNA）・tRNA（転移 RNA）・rRNA（リボソーム RNA）があり、タンパク質の合成にはたらく。DNA の複製や、塩基配列からタンパク質ができるしくみは、教科書では「発展」として扱う。

塩基の割合は、対で数える数える

二重らせんの DNA では、A と T、G と C がいつも対になるので、A と T の数、G と C の数はそれぞれ等しい。A が塩基全体の 30% なら、T も 30%、残りの 40% を G と C が半分ずつ分けて 20% ずつになる。

よく出る疑問

Q1糖の還元性は、なぜアルデヒドの銀鏡反応と同じと言えるのか。

グルコースは、水溶液中で環が開いた鎖状構造をとり、そこに −CHO がある。この −CHO が、アセトアルデヒドの −CHO と同じように酸化されて、Ag+ や Cu2+ を還元する。

Q2デンプンとセルロースは、同じグルコースからできているのに、なぜ性質がちがうのか。

デンプンは α-グルコース、セルロースは β-グルコースからできていて、つながり方の向きがちがう。デンプンの鎖はらせんを巻くが、セルロースは直線状にのびて分子どうしが水素結合で強く結びつく。そのため、セルロースは繊維になり、ヨウ素デンプン反応も示さない。

Q3ジペプチドはビウレット反応を示すか。

示さない。ビウレット反応にはペプチド結合が 2 つ以上必要で、アミノ酸 3 分子以上のペプチド（トリペプチド以上）が反応する。

Q4等電点のアミノ酸は、水溶液中ですべて双性イオンなのか。

ほとんどが双性イオンで、陽イオンと陰イオンがごくわずかに等量ある。全体として電荷が 0 になるので、電気泳動でどちらの極にも移動しない。

Q5塩析と変性は、どうちがうのか。

塩析は、多量の電解質を加えて、タンパク質に水和している水分子を奪って沈殿させるものである。変性は、熱・酸・塩基・重金属イオン・有機溶媒などで立体構造が変わり、性質や機能が失われるもので、もとにもどらないことが多い。
