反応はどちらへ進むか

混ぜた物質が反応するかどうか、どちら向きに進むかは、できるものが水溶液の中のイオンの集まりから抜けていくかどうかで決まる。

抜けていくものができる向きに進む・① 電離しにくい分子になる・② 気体として系の外へ出ていく・③ 沈殿として抜ける・錯イオンができると沈殿が溶ける・酸化還元の向き・よく出る疑問

先に要るもの：何をやりとりする反応か

抜けていくものができる向きに進む

理論：化学平衡

水溶液の中で、イオンは自由に動きまわって、ぶつかり合っている。イオンどうしが結びついてできたものが、そのまま水溶液の中にイオンとして残るなら、結びつきとほどけが行き来するだけで、全体としては何も変わらない。

たとえば塩化ナトリウム水溶液と硝酸カリウム水溶液を混ぜても、Na+・Cl−・K+・NO3− がまざるだけで、気体も沈殿も水もできない。このときは反応式を書かない（反応が起こらない）。

ところが、できたものが水溶液のイオンの集まりから抜けていくと、逆向きの反応の相手が減るので、平衡が右へ移り続ける（ルシャトリエの原理）。抜けていく形は次の3つである。

① 電離しにくい分子になる

水や弱酸・弱塩基は、水溶液の中でほとんど電離しない。イオンがこれらの分子になると、イオンとしては水溶液から抜けたのと同じことになる。

弱酸の遊離酸塩基理論：化学平衡理論：電離平衡
CH3COO− + H+ → CH3COOHイオン反応式
CH3COONa + HCl → CH3COOH + NaCl

酢酸は弱酸なので、H+ を受け取った CH3COO− は、ほとんどが電離しない CH3COOH のまま残る。「強い酸＋弱い酸の塩 → 強い酸の塩＋弱い酸」は、この見方の言いかえである。弱い酸が CO2・H2S・SO2 のように気体になるものなら、②も重なってさらに進みやすい。

中和酸塩基
H+ + OH− → H2Oイオン反応式

水はほとんど電離しないので、H+ と OH− はほぼすべて水になる。

同じ型の反応：

  • 反応の進む向き › 弱酸の遊離
  • 反応の進む向き › 中和
  • 反応の進む向き › 弱塩基の遊離でアンモニアが出る
  • 酸塩基 › 中和
  • 酸塩基 › 弱酸の遊離
  • 酸塩基 › 弱塩基の遊離
  • 気体の発生 › 二酸化炭素
  • 気体の発生 › 硫化水素
  • 気体の発生 › 二酸化硫黄（弱酸の遊離）
  • 気体の発生 › アンモニア
  • 気体の発生 › フッ化水素
  • ハロゲン › フッ化水素：ホタル石と濃硫酸（加熱）
  • 酸素・硫黄 › 製法（弱酸の遊離）
  • 酸素・硫黄 › 希硫酸：強酸
  • 窒素・リン › 製法（弱塩基の遊離）
  • 炭素・ケイ素 › 製法（弱酸の遊離）
  • 炭素・ケイ素 › ケイ酸ナトリウムからシリカゲルまで
  • アルカリ金属・アルカリ土類金属 › 酸との反応

② 気体として系の外へ出ていく

できた物質が気体になって水溶液（反応の系）の外へ出ていくと、もどってこないので、反応は右へ進み続ける。加熱すると気体はさらに出ていきやすくなる。

揮発性の酸の遊離酸塩基理論：化学平衡
NaCl + H2SO4 → NaHSO4 + HCl

HCl は強酸なので、酸の強さからはこの向きに進む理由が出てこない。進むのは、HCl が揮発性で、加熱すると気体として出ていくからである。硫酸は沸点が高く、出ていかない。

弱塩基の遊離でアンモニアが出る酸塩基
2NH4Cl + Ca(OH)2 → CaCl2 + 2H2O + 2NH3

NH4+ から H+ が OH− に移って NH3 と H2O ができ、加熱で NH3 が気体として出ていく。

同じ型の反応：

  • 反応の進む向き › 揮発性の酸の遊離
  • 反応の進む向き › 弱塩基の遊離でアンモニアが出る
  • 酸塩基 › 弱酸の遊離
  • 酸塩基 › 弱塩基の遊離
  • 酸塩基 › 揮発性の酸の遊離
  • 気体の発生 › 二酸化炭素
  • 気体の発生 › 硫化水素
  • 気体の発生 › 二酸化硫黄（弱酸の遊離）
  • 気体の発生 › アンモニア
  • 気体の発生 › 塩化水素
  • 気体の発生 › フッ化水素
  • 気体の発生 › アセチレン
  • ハロゲン › 塩化水素：塩化ナトリウムと濃硫酸（加熱）
  • ハロゲン › フッ化水素：ホタル石と濃硫酸（加熱）
  • 酸素・硫黄 › 製法（弱酸の遊離）
  • 酸素・硫黄 › 製法
  • 酸素・硫黄 › 濃硫酸：不揮発性
  • 窒素・リン › 製法（弱塩基の遊離）
  • 炭素・ケイ素 › 製法（弱酸の遊離）
  • アルカリ金属・アルカリ土類金属 › 酸との反応

③ 沈殿として抜ける

理論：電離平衡

水に溶けにくい塩ができると、固体として水溶液から抜ける。どの組合せが沈殿するかは覚える（覚えることのページ）が、沈殿ができれば反応が進む、という向きの決まり方は気体と同じである。

炭酸カルシウムの沈殿覚える
Ca2+ + CO32− → CaCO3イオン反応式
CaCl2 + Na2CO3 → CaCO3 + 2NaCl

陽イオンと陰イオンの組合せが変わるだけで、H+ も e− も移らない。

同じ型の反応：

  • 反応の進む向き › 炭酸カルシウムの沈殿
  • ハロゲン › ハロゲン化銀の沈殿
  • 酸素・硫黄 › 金属イオンとの沈殿
  • 炭素・ケイ素 › 石灰水との反応
  • アルカリ金属・アルカリ土類金属 › 硫酸塩と炭酸塩の溶けやすさ
  • アルミニウム・亜鉛・スズ・鉛 › 鉛の化合物
  • 遷移元素 › 水酸化物の沈殿と検出
  • 遷移元素 › 酸化銀の沈殿
  • 遷移元素 › クロム酸塩の沈殿

錯イオンができると沈殿が溶ける

逆に、沈殿していた物質のイオンが、別の形で水溶液の中に取りこまれると、沈殿は溶けていく。

塩化銀とアンモニア水覚える理論：化学平衡理論：化学結合・分子間力
AgCl ⇄ Ag+ + Cl−イオン反応式
AgCl + 2NH3 → [Ag(NH3)2]+ + Cl−

AgCl の沈殿のそばにも、ごくわずかな Ag+ がある。NH3 が Ag+ と結びついて錯イオン [Ag(NH3)2]+ になると、Ag+ が減るので、1つ目の平衡が右へ移り、沈殿が溶けていく。

同じ型の反応：

  • 反応の進む向き › 塩化銀とアンモニア水
  • ハロゲン › 塩化銀とアンモニア水
  • アルミニウム・亜鉛・スズ・鉛 › 水酸化亜鉛
  • 遷移元素 › 水酸化銅(Ⅱ)とアンモニア水
  • 遷移元素 › ジアンミン銀(Ⅰ)イオン

酸化還元の向き

酸化還元反応は、強い酸化剤と強い還元剤が反応して、弱い還元剤と弱い酸化剤ができる向きに進む。

ハロゲンの置換酸化還元
Cl2 + 2KI → 2KCl + I2

酸化力は Cl2 ＞ I2。強い酸化剤 Cl2 と強い還元剤 I− から、弱い還元剤 Cl− と弱い酸化剤 I2 ができる。逆向きには進まない。

金属と金属イオン酸化還元理論：電池・電気分解
Zn + Cu2+ → Zn2+ + Cuイオン反応式

イオン化傾向は Zn ＞ Cu。陽イオンになりやすい金属ほど強い還元剤である。

イオン化傾向：Li ＞ K ＞ Ca ＞ Na ＞ Mg ＞ Al ＞ Zn ＞ Fe ＞ Ni ＞ Sn ＞ Pb ＞ (H2) ＞ Cu ＞ Hg ＞ Ag ＞ Pt ＞ Au

ハロゲンの単体の酸化力：F2 ＞ Cl2 ＞ Br2 ＞ I2

同じ型の反応：

  • 反応の進む向き › ハロゲンの置換
  • 反応の進む向き › 金属と金属イオン
  • ハロゲン › ハロゲンの置換
  • 酸素・硫黄 › 二酸化硫黄との反応

よく出る疑問

Q1塩化水素の製法で、希硫酸ではなく濃硫酸を使うのはなぜか。

希硫酸には水が多く、できた HCl は水によく溶けるので、気体として出ていかない。水の少ない濃硫酸と加熱すると、HCl が系の外へ出ていき、反応が右へ進む。

Q2塩化ナトリウムと濃硫酸の反応は、硫酸水素ナトリウムで止まるのか。

実験室で加熱する程度では、NaHSO4 ができる式で書く。さらに高い温度にすると、NaHSO4 の残りの H+ も使われて Na2SO4 まで進む。

2NaCl + H2SO4 → Na2SO4 + 2HCl
Q3酸化還元の反応も、気体が出ると進みやすくなるのか。

向きを決めているのは酸化剤・還元剤の強さである。銅は H+ では酸化されないので、塩酸に入れても H2 は出ない。亜鉛と塩酸のように進む向きの反応では、H2 が出ていくので逆向きの反応は起こらなくなる。
