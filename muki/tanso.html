炭素・ケイ素

CO₂ と SiO₂ はどちらも14族の酸性酸化物で、塩基との反応は同じ形で書ける。

反応の地図（炭素とケイ素）

つながる地図：カルシウム（CaCO₃ ⇄ CaO の輪）・鉄（CO が Fe₂O₃ を還元する製鉄）・酸化数の範囲（C は ＋4 から −4）

炭素の単体・一酸化炭素・二酸化炭素・ケイ素・二酸化ケイ素・水ガラスとシリカゲル・過去問で確かめる

先に要るもの：半反応式の作り方、反応はどちらへ進むか

炭素の単体

理論：化学結合・分子間力

ダイヤモンド・黒鉛・フラーレン・カーボンナノチューブは同素体である覚える。ダイヤモンドは各 C が4個の C と共有結合した立体の網目で、非常に硬く電気を通さない。黒鉛は各 C が3個の C と結合した平面の層が重なったもので、層の中を動ける電子があるので電気を通す。

一酸化炭素

無色・無臭の有毒な気体で、水に溶けにくい。C の酸化数は ＋2 で、さらに酸化されて ＋4 になりやすいので、還元剤としてはたらく。

製法覚える
HCOOH → H2O + CO

ギ酸に濃硫酸を加えて加熱する（脱水作用）。

還元剤としてのはたらき酸化還元
CuO + CO → Cu + CO2

金属の酸化物から O を奪い、金属の単体にする。製鉄の溶鉱炉で Fe2O3 を還元するのもこの反応である（遷移元素のページ）。

二酸化炭素

酸塩基

無色・無臭の気体で、空気より重く、水に少し溶けて弱い酸性を示す。固体はドライアイスで、昇華しやすい。

製法（弱酸の遊離）→電離しにくい分子になる→気体が出ていく
CaCO3 + 2HCl → CaCl2 + H2O + CO2
水との反応
CO2 + H2O ⇄ H+ + HCO3−イオン反応式
石灰水との反応→沈殿して抜ける理論：化学平衡
Ca(OH)2 + CO2 → CaCO3 + H2O
CaCO3 + CO2 + H2O → Ca(HCO3)2

1つ目は酸性酸化物と塩基の中和で、白い CaCO3 の沈殿ができる（CO2 の検出）。さらに CO2 を通すと、CO32− が H+ を受け取って HCO3− になり、水に溶ける Ca(HCO3)2 になって白濁が消える。加熱すると逆向きに進む。石灰岩が CO2 を含む水に溶けていく向きで鍾乳洞ができ、CO2 が抜ける逆向きで鍾乳石や石筍ができる。

ケイ素

ケイ素の単体は、ダイヤモンドと同じ形の共有結合の結晶で、天然には単体として存在しない覚える。金属と非金属の中間の電気伝導性をもち（半導体）、太陽電池や集積回路に使う。

単体の製法酸化還元
SiO2 + 2C → Si + 2CO

電気炉で強熱し、C で SiO2 を還元する。Si は ＋4 から 0、C は 0 から ＋2 になる。

二酸化ケイ素

理論：化学結合・分子間力

石英・水晶・ケイ砂の主成分で、Si と O が交互に共有結合した立体の網目をつくる。硬く、融点が高い。光ファイバーやガラスの原料に使う覚える。

塩基との反応酸塩基
SiO2 + 2NaOH → Na2SiO3 + H2O

酸性酸化物と塩基の反応。NaOH（または Na2CO3）と加熱して融かすと、ケイ酸ナトリウムができる。CO2 + 2NaOH → Na2CO3 + H2O と同じ形である。

フッ化水素酸との反応覚える
SiO2 + 6HF → H2SiF6 + 2H2O

フッ化水素酸はガラスを溶かす（ハロゲンのページ）。

水ガラスとシリカゲル

ケイ酸ナトリウムからシリカゲルまで酸塩基覚える→電離しにくい分子になる
Na2SiO3 + 2HCl → H2SiO3 + 2NaCl

ケイ酸ナトリウムに水を加えて加熱すると、粘り気のある液体（水ガラス）になる。水ガラスに塩酸を加えると、弱酸のケイ酸が遊離して白いゲル状の沈殿になる（弱酸の遊離）。ケイ酸を加熱して乾燥させたものがシリカゲルで、多孔質で表面積が大きく、表面の −OH に水などが吸着するので乾燥剤に使う。どの段で何ができるかの名前は覚える覚える。
