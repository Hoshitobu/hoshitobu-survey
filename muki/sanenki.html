酸塩基

酸塩基反応は H⁺ のやりとりである。

H⁺ を渡す側と受け取る側

酸と塩基・酸・塩基の強弱・中和と塩の液性・弱酸・弱塩基・揮発性の酸の遊離・酸化物と水・酸・塩基・過去問で確かめる

先に要るもの：何をやりとりする反応か

酸と塩基

水素イオン H+ を与える物質が酸、受け取る物質が塩基である（ブレンステッド・ローリーの定義）。水溶液中で H+ を出す物質を酸、OH− を出す物質を塩基とするアレニウスの定義も、この中に含まれる。

アンモニアと水酸塩基
NH3 + H2O ⇄ NH4+ + OH−イオン反応式

NH3 は H2O から H+ を受け取るので塩基、H2O は H+ を与えるので酸としてはたらいている。NH3 自身は OH− をもたないが、水溶液は塩基性を示す。

酸・塩基の強弱

水溶液中でほぼ完全に電離するものが強酸・強塩基、一部しか電離しないものが弱酸・弱塩基である。どれが強いかは覚える覚える。

強い弱い
酸HCl・HBr・HI・HNO3・H2SO4HF・CH3COOH・H2CO3（CO2 ＋ H2O）・H2S
塩基NaOH・KOH・Ca(OH)2・Ba(OH)2NH3・Mg(OH)2・Cu(OH)2・水酸化鉄(Ⅲ)

弱い酸どうしにも強弱がある。気体の製法でよく使うのは、強酸 ＞ CH3COOH ＞ H2CO3 の順である。

中和と塩の液性

中和酸塩基→電離しにくい分子になる
H+ + OH− → H2Oイオン反応式
H2SO4 + 2NaOH → Na2SO4 + 2H2O

酸の H+ と塩基の OH− から水ができ、残りの陰イオンと陽イオンが塩になる。

塩の水溶液の液性は、もとになった酸と塩基の強さで決まる。弱い方のイオンが水と H+ をやりとりする（加水分解）からである。

もとの酸と塩基液性例
強酸＋強塩基中性NaCl・KNO3・Na2SO4
強酸＋弱塩基酸性NH4Cl・NH4NO3・CuSO4
弱酸＋強塩基塩基性CH3COONa・Na2CO3・NaHCO3
加水分解酸塩基理論：電離平衡
NH4+ + H2O ⇄ NH3 + H3O+イオン反応式
CH3COO− + H2O ⇄ CH3COOH + OH−

弱塩基 NH3 に H+ がついた NH4+ は水に H+ を与え、弱酸 CH3COOH から H+ がとれた CH3COO− は水から H+ を受け取る。強酸の陰イオン（Cl−・NO3−・SO42−）や強塩基の陽イオン（Na+・K+）は、ほとんど H+ をやりとりしない。

酸性塩の液性酸塩基
HSO4− → H+ + SO42−イオン反応式

NaHSO4 の水溶液は酸性。HSO4− がさらに H+ を出すからである。一方、NaHCO3 の水溶液は弱い塩基性になる。塩の名前に「酸性塩」とあっても液性が酸性とは限らないので、イオンが H+ を出すか受け取るかで考える。

弱酸・弱塩基・揮発性の酸の遊離

酸塩基

弱い酸の塩に強い酸を加えると、H+ は弱い酸の陰イオンに移って弱い酸ができる。気体の製法の多くはこの形である。

弱酸の遊離→電離しにくい分子になる→気体が出ていく理論：化学平衡理論：電離平衡
CO32− + 2H+ → H2O + CO2イオン反応式
CaCO3 + 2HCl → CaCl2 + H2O + CO2
FeS + H2SO4 → FeSO4 + H2S
Na2SO3 + H2SO4 → Na2SO4 + H2O + SO2
Na2SiO3 + 2HCl → H2SiO3 + 2NaCl

炭酸 H2CO3 と亜硫酸 H2SO3 は不安定で、水と気体（CO2、SO2）に分かれる。どの式でも酸化数は変わらない。

弱塩基の遊離→電離しにくい分子になる→気体が出ていく
NH4+ + OH− → NH3 + H2Oイオン反応式
2NH4Cl + Ca(OH)2 → CaCl2 + 2H2O + 2NH3

強い塩基の OH− が、NH4+（弱い塩基 NH3 に H+ がついたもの）から H+ を受け取る。装置と乾燥は窒素のページ。

揮発性の酸の遊離→気体が出ていく
NaCl + H2SO4 → NaHSO4 + HCl
CaF2 + H2SO4 → CaSO4 + 2HF

強酸の HCl が出てくる理由は、酸の強さではなく、気体として出ていくことにある（反応はどちらへ進むか）。

酸化物と水・酸・塩基

酸塩基

非金属元素の酸化物の多くは酸性酸化物で、水と反応して酸（オキソ酸）になり、塩基と中和する（SiO2 のように水とは反応しないものもある。CO・NO は酸性酸化物ではない）。金属元素の酸化物の多くは塩基性酸化物で、酸と中和する（水と反応して塩基になるのは Na2O・CaO など。CuO・Fe2O3 は水とは反応しない）。Al2O3・ZnO のように酸とも塩基とも反応するものは両性酸化物という。

同じ周期では、左の元素（陽性が強い）の酸化物ほど塩基性が強く、右の元素（陰性が強い）の酸化物ほど酸性が強い。第3周期なら Na2O・MgO が塩基性、Al2O3 が両性、SiO2・P4O10・SO3・Cl2O7 が酸性である。

酸性酸化物
SO3 + H2O → H2SO4
CO2 + 2NaOH → Na2CO3 + H2O
SiO2 + 2NaOH → Na2SiO3 + H2O

CO2 を塩基と反応させると、H2CO3 の2つの H+ が OH− と中和したのと同じ塩ができる。SiO2 は NaOH と加熱して融かすと反応する。

塩基性酸化物
CaO + H2O → Ca(OH)2
CaO + 2HCl → CaCl2 + H2O
O2− + 2H+ → H2Oイオン反応式

酸化物イオン O2− が H+ を受け取る塩基としてはたらく。

両性酸化物
Al2O3 + 6HCl → 2AlCl3 + 3H2O
Al2O3 + 2NaOH + 3H2O → 2Na[Al(OH)4]

塩基との反応でできる [Al(OH)4]− の形は覚える。アルミニウム・亜鉛のページも参照。

酸性酸化物と塩基性酸化物から塩、熱分解はその逆
CaO + CO2 → CaCO3
CaCO3 → CaO + CO2　（加熱）
2NaHCO3 → Na2CO3 + H2O + CO2　（加熱）

炭酸塩や水酸化物を加熱したときの分解は、酸性酸化物（CO2）や水が抜ける向きの反応で、どの原子の酸化数も変わらない。NaHCO3 の分解は、HCO3− の1つがもう1つに H+ を渡して CO32− と H2CO3 になり、H2CO3 が H2O と CO2 に分かれる、と読める。どの温度で分解するかは覚える。
