アルミニウム・亜鉛・スズ・鉛

Al・Zn・Sn・Pb は両性金属で、単体は酸とも強塩基とも反応する（Pb は希塩酸・希硫酸には溶けにくい）。

反応の地図（アルミニウムと亜鉛）

つながる地図：銅（アンモニア水で溶ける錯イオン）・どこから沈殿するか（Al・Zn・Pb は NaOH 過剰で溶ける）

両性金属と酸・塩基・両性水酸化物・アルミニウム・スズ・鉛・過去問で確かめる

先に要るもの：半反応式の作り方、反応はどちらへ進むか

両性金属と酸・塩基

酸との反応酸化還元
2Al + 6HCl → 2AlCl3 + 3H2
Zn + 2HCl → ZnCl2 + H2

金属が電子を与え、H+ が受け取って H2 になる。

強塩基との反応酸化還元覚える
2Al + 2NaOH + 6H2O → 2Na[Al(OH)4] + 3H2
Zn + 2NaOH + 2H2O → Na2[Zn(OH)4] + H2

金属は水の H（＋1）に電子を与えて H2 を発生させ、自身はイオンになる。できた Al3+ や Zn2+ は、多量の OH− と結びついてヒドロキシド錯イオン [Al(OH)4]−・[Zn(OH)4]2− になる。錯イオンの形は覚える覚える。

反応が進まない組合せ覚える

Al は濃硝酸には溶けない（不動態、酸化還元のページ）。Pb は希塩酸・希硫酸とは、表面が難溶性の PbCl2・PbSO4 でおおわれて、ほとんど反応しない。

両性水酸化物

酸塩基覚える
酸化アルミニウム（両性酸化物）
Al2O3 + 6HCl → 2AlCl3 + 3H2O
Al2O3 + 2NaOH + 3H2O → 2Na[Al(OH)4]

酸とも強塩基とも反応する。塩基との反応でできる [Al(OH)4]− の形は覚える。

水酸化アルミニウム
Al3+ + 3OH− → Al(OH)3イオン反応式
Al(OH)3 + 3HCl → AlCl3 + 3H2O
Al(OH)3 + NaOH → Na[Al(OH)4]

Al3+ を含む水溶液に塩基を少し加えると、白いゲル状の Al(OH)3 が沈殿する。Al(OH)3 は酸と中和して溶け、強塩基を過剰に加えても [Al(OH)4]− になって溶ける。アンモニア水を過剰に加えても溶けない（NH3 は弱い塩基で OH− が少ない）。

水酸化亜鉛→錯イオンになって溶ける理論：化学結合・分子間力
Zn2+ + 2OH− → Zn(OH)2イオン反応式
Zn(OH)2 + 2NaOH → Na2[Zn(OH)4]
Zn(OH)2 + 4NH3 → [Zn(NH3)4]2+ + 2OH−

Zn(OH)2 は白色の沈殿で、強塩基にも、アンモニア水にも溶ける。アンモニア水に溶けて [Zn(NH3)4]2+ になることは、Al(OH)3 とのちがいとして覚える覚える。

アルミニウム

溶融塩電解（ホール・エルー法）酸化還元理論：電池・電気分解
Al3+ + 3e− → Al　（陰極）半反応式
C + O2− → CO + 2e−　（陽極）
C + 2O2− → CO2 + 4e−　（陽極）

ボーキサイトから精製した酸化アルミニウム（アルミナ）を、融解した氷晶石 Na3AlF6 に溶かして電気分解する。融解した氷晶石にアルミナを溶かすと、アルミナだけを融かすよりずっと低い温度で電気分解できる覚える。Al はイオン化傾向が大きいので、水溶液を電気分解しても陰極では H2 が出て、Al は得られない。陽極の炭素は O2− と反応して CO・CO2 になり、消耗する。

テルミット反応酸化還元
2Al + Fe2O3 → Al2O3 + 2Fe

Al は O と強く結びつくので、酸化鉄(Ⅲ) から O を奪って鉄を遊離させる。多量の熱が出て、鉄は融けた状態で得られる。

ミョウバン覚える

硫酸カリウムアルミニウム十二水和物 AlK(SO4)2·12H2O は複塩で、水に溶かすと Al3+・K+・SO42− に電離する。Al3+ の加水分解で水溶液は弱い酸性を示す（酸塩基）。

スズ・鉛

スズ(Ⅱ)イオンの還元作用酸化還元
Sn2+ → Sn4+ + 2e−半反応式

Sn は ＋2 と ＋4 の化合物をつくり、＋4 の方が安定なので、SnCl2 は還元剤としてはたらく。

鉛の化合物覚える→沈殿して抜ける

Pb は ＋2 の化合物が安定である。PbCl2（白色、熱水には溶ける）、PbSO4（白色）、PbCrO4（黄色）、PbS（黒色）はどれも沈殿する。Pb2+ の検出に使う。鉛蓄電池の負極は Pb、正極は PbO2 である。

合金とめっき覚える理論：電池・電気分解

ブリキは鉄にスズを、トタンは鉄に亜鉛をめっきしたもの。はんだはスズと鉛（現在は鉛を含まないものが多い）、青銅は銅とスズ、黄銅は銅と亜鉛の合金である。トタンは傷がついても、鉄よりイオン化傾向の大きい亜鉛が先に酸化されるので、鉄がさびにくい酸化還元。
