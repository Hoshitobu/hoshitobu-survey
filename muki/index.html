無機化学は2つの道具で書ける

無機化学の反応は、何をやりとりするか・どちらへ進むか・何を覚えるか、の3つで整理できる。

学ぶ順番

上の段から。問いに答えられたら下の段へ、答えられなければその段のページから読む。

先に要るもの

問いMnO₄⁻ の Mn の酸化数を出せるか。NH₃ と水の反応で、どちらが H⁺ を渡したか言えるか。

答え

Mn は ＋7（x ＋ 4×(−2) ＝ −1）。NH3 + H2O ⇄ NH4+ + OH− で、H+ を渡したのは H2O。

答えられなければ酸化数酸と塩基の定義

考え方の芯

問い反応式を見て、酸塩基・酸化還元・どちらでもない、に分けられるか。塩化ナトリウム水溶液と硝酸カリウム水溶液を混ぜても反応しない理由を言えるか。

答え

酸化数が変わる原子があれば酸化還元、なく H+ が移れば酸塩基、どちらでもなければ沈殿か錯イオン。NaCl と KNO3 では、電離しにくい分子・気体・沈殿のどれもできないので、イオンがまざるだけである。

答えられなければ何をやりとりする反応か反応はどちらへ進むか

2つの道具

問い炭酸カルシウムと塩酸の反応式を、H⁺ の移り方から書けるか。酸性の Cr₂O₇²⁻ が Cr³⁺ になる半反応式を組み立てられるか。

答え
CaCO3 + 2HCl → CaCl2 + H2O + CO2
Cr2O72− + 14H+ + 6e− → 2Cr3+ + 7H2O半反応式

答えられなければ酸塩基酸化還元気体の発生

元素ごと

  • 1・2族アルカリ金属・アルカリ土類金属
  • 3〜12族遷移元素（Zn は両性金属の欄）
  • Zn・Al・Sn・Pb両性金属
  • 14族C・Si
  • 15族N・P
  • 16族O・S
  • 17族ハロゲン

何をやりとりする反応か

反応式を書く前に、反応する物質どうしが何をやりとりするかを見分ける。無機化学の反応のほとんどは、次の3つのどれかに入る。

H⁺ をやりとりする：酸塩基反応酸塩基

H+ を与える物質が酸、受け取る物質が塩基（ブレンステッドの定義）。どの原子の酸化数も変わらない。中和、塩の加水分解、弱酸の遊離、酸化物と水・酸・塩基の反応がここに入る。金属イオンと OH− から水酸化物が沈殿する反応（Cu2+ + 2OH− → Cu(OH)2）も、強い塩基が弱い塩基を追い出す反応（弱塩基の遊離）と見て、ここに入れる。

CO32− + 2H+ → H2O + CO2イオン反応式

くわしくは酸塩基のページ。

e⁻ をやりとりする：酸化還元反応酸化還元

電子を受け取る物質が酸化剤、与える物質が還元剤。酸化数が変わる原子がある。金属と酸、ハロゲンの置換、気体の製法の半分ほど、電気分解がここに入る。

Cl2 + 2I− → 2Cl− + I2イオン反応式

くわしくは酸化還元のページ。

どちらでもない：組合せが変わる・配位する覚える

陽イオンと陰イオンの組合せが変わって沈殿ができる反応と、金属イオンに分子やイオンが配位して錯イオンができる反応。H+ も e− も移らない。式は組合せを書くだけだが、どの組合せが沈殿するか、何が配位するかは覚える。脱水・同素体の変化・水和水の出入りのように、3つのどれにも入らない反応も少しある（覚える）。

Ag+ + Cl− → AgClイオン反応式

見分け方

  1. 反応の前後で、酸化数が変わる原子があるかを見る。あれば酸化還元。
  2. 酸化数が変わらず、H+ がある物質から別の物質へ移っていれば酸塩基。
  3. どちらでもなければ、沈殿か錯イオン。

式の書き方

どの反応も、まずイオン反応式で書く。実際に変化するイオンだけを残すと、何と何が反応したのかがはっきりする。

イオン反応式の書き方（例：硝酸銀水溶液と塩化ナトリウム水溶液）

イオン反応式（沈殿の例：硝酸銀水溶液と塩化ナトリウム水溶液）

  1. 水溶液中の物質を、電離した形で並べる。
  2. 抜けていくもの（沈殿・気体・電離しにくい分子）を組み立てる。
  3. 反応の前後で変わらないイオンを両辺から消す。
  4. 化学反応式が要るときは、消したイオンを両辺にもどす。
STEP 1

電離した形で並べる

AgNO3 と NaCl は、水溶液中では電離している。

Ag+ + NO3− + Na+ + Cl− →イオン反応式
STEP 2

抜けていくものを組み立てる

4種類のイオンの組合せのうち、水に溶けにくい AgCl が沈殿する。

Ag+ + NO3− + Na+ + Cl− → AgCl + NO3− + Na+イオン反応式
STEP 3

変わらないイオンを消す

NO3− と Na+ は反応の前後で変わらない。

Ag+ + Cl− → AgClイオン反応式
STEP 4

化学反応式にもどす

消したイオンを両辺に足して、物質の形にまとめる。

AgNO3 + NaCl → AgCl + NaNO3
酸塩基の式の書き方（例：炭酸カルシウムと塩酸）

酸塩基の式（例：炭酸カルシウムと塩酸）

  1. H+ を出す物質と、受け取る物質を決める。
  2. H+ を移す。
  3. 不安定な物質があれば分ける。
  4. 省いたイオンを足して化学反応式にする。
STEP 1

H⁺ を出す物質と受け取る物質

強酸の HCl が H+ を出し、弱酸 H2CO3 の陰イオン CO32− が受け取る。

STEP 2

H⁺ を移す

CO32− + 2H+ → H2CO3イオン反応式
STEP 3

不安定な物質を分ける

炭酸は水と二酸化炭素に分かれる。

CO32− + 2H+ → H2O + CO2イオン反応式
STEP 4

化学反応式にする

両辺に Ca2+ と 2Cl− を足す。

CaCO3 + 2HCl → CaCl2 + H2O + CO2
酸化還元の式の書き方（例：塩素とヨウ化カリウム）

酸化還元の式（例：塩素とヨウ化カリウム）

  1. 酸化剤と還元剤が何に変わるかを書く。
  2. O は H2O、H は H+、電荷は e− でそろえて、半反応式にする。
  3. e− の数をそろえて足す。
  4. 省いたイオンを足して化学反応式にする。
STEP 1

何に変わるか

酸化剤の Cl2 は Cl− に、還元剤の I− は I2 に変わる。

STEP 2

半反応式にする

O も H もないので、電荷を e− でそろえるだけでよい。

Cl2 + 2e− → 2Cl−半反応式
2I− → I2 + 2e−
STEP 3

e⁻ をそろえて足す

Cl2 + 2I− → 2Cl− + I2イオン反応式
STEP 4

化学反応式にする

両辺に 2K+ を足す。

Cl2 + 2KI → 2KCl + I2

O や H を含む酸化剤（MnO4−・Cr2O72− など）の半反応式の作り方は酸化還元のページ。

2つの道具で書けないこと

2つの道具で出せるのは、反応するとしたら何ができるかと、係数である。次のことは道具からは出せないので覚える。このサイトでは「覚える」の札をつけ、覚えることのページに集めている。

  • 酸化剤・還元剤が何に変わるか（例：酸性の MnO4− は Mn2+ になる）。ここだけ覚えれば、半反応式の残りは出せる。
  • 物質やイオンの色、どの組合せが沈殿するか。
  • 錯イオンの形と配位数、炎色反応の色。
  • 反応が実際に進むかどうか（不動態、表面を難溶性の塩がおおう場合）と、反応の速さ。
  • 工業的製法の触媒・温度・圧力などの条件、物質の用途と保存法。
