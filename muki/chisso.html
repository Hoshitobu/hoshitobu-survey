窒素・リン

窒素の化合物は、N の酸化数が −3（NH₃）から ＋5（HNO₃）まで大きく変わる。

反応の地図（窒素）

つながる地図：硫黄（オストワルト法と接触法は同じ形）・ナトリウム（アンモニアソーダ法で NH₃ を回収）・酸化数が上と下に分かれる反応（NO₂＋H₂O）

アンモニア・一酸化窒素・二酸化窒素・硝酸・リン・過去問で確かめる

先に要るもの：半反応式の作り方、反応はどちらへ進むか

アンモニア

無色・刺激臭の気体で、水によく溶けて弱い塩基性を示す。N の酸化数は −3。

製法（弱塩基の遊離）酸塩基→電離しにくい分子になる→気体が出ていく
2NH4Cl + Ca(OH)2 → CaCl2 + 2H2O + 2NH3

上方置換で集める。乾燥には、中和しないソーダ石灰を使う（濃硫酸・P4O10 は中和するので使えず、CaCl2 は NH3 を吸収するので使えない）。

水・塩化水素との反応酸塩基理論：化学結合・分子間力
NH3 + H2O ⇄ NH4+ + OH−イオン反応式
NH3 + HCl → NH4Cl

濃塩酸をつけたガラス棒を近づけると白煙ができるので、NH3 の検出に使う。

ハーバー・ボッシュ法酸化還元理論：化学平衡理論：反応速度・触媒理論：反応エンタルピー
N2 + 3H2 ⇄ 2NH3　（正反応は発熱）

N が 0 から −3 に還元され、H が 0 から ＋1 に酸化される。触媒は四酸化三鉄 Fe3O4 を主成分とするもの覚える。

見方温度圧力
平衡（NH3 の割合）正反応は発熱反応。温度を下げると、熱を出す向き（右）へ平衡が移るので、低温ほど NH3 が多い。気体の分子は左辺 4 個、右辺 2 個。圧力を上げると、分子の数が減る向き（右）へ平衡が移るので、高圧ほど NH3 が多い。
速さ低温では反応が遅く、平衡に達するまでに時間がかかる。高圧では気体の濃度が大きく、反応も速くなる。
実際触媒で反応を速くしたうえで、NH3 の割合と速さがつりあう、ある程度の高温で行う。高圧で行う。

触媒は反応を速くするだけで、平衡の位置（NH3 の割合）は変えない。できた NH3 は冷やして液体にして取り出す。NH3 を取り除くと平衡は右へ移る（抜けていくものができる向きに進むのと同じ見方）。反応しなかった N2・H2 はもどしてまた使う。

一酸化窒素・二酸化窒素

NONO2
N の酸化数＋2＋4
色無色赤褐色
水への溶け方溶けにくい溶けて反応する
製法銅＋希硝酸銅＋濃硝酸
捕集水上置換下方置換
一酸化窒素と酸素酸化還元
2NO + O2 → 2NO2

空気にふれるとすぐ赤褐色の NO2 になる。

二酸化窒素の二量体覚える理論：化学平衡理論：反応エンタルピー
2NO2 ⇄ N2O4

無色の四酸化二窒素との間で平衡になる。N の酸化数は ＋4 のまま。冷やすと色が薄くなる。

硝酸

無色の液体で、強酸であり、N の酸化数が ＋5 と最も高いので強い酸化剤でもある。光や熱で分解しやすいので、褐色のびんに入れて冷暗所に保存する覚える。

酸化剤としてのはたらき酸化還元
HNO3 + 3H+ + 3e− → NO + 2H2O　（希硝酸）半反応式
HNO3 + H+ + e− → NO2 + H2O　（濃硝酸）

Cu・Ag のように H+ では酸化されない金属も溶かす。反応式は酸化還元のページ。Al・Fe・Ni が濃硝酸に溶けない（不動態）ことは酸化還元のページ。

オストワルト法（硝酸の工業的製法）酸化還元覚える理論：反応速度・触媒
4NH3 + 5O2 → 4NO + 6H2O　（触媒 Pt）
2NO + O2 → 2NO2
3NO2 + H2O → 2HNO3 + NO

N の酸化数は −3 → ＋2 → ＋4 と上がっていく。3段目は1種類の物質の中で酸化（＋4 → ＋5）と還元（＋4 → ＋2）が同時に起こる。3段目で出た NO はまた2段目に戻す。触媒が白金であることは覚える覚える。

流れは接触法と同じ形（酸化を重ねて、水で酸にする）。ちがいは最後の段が酸化還元であること（接触法の最後の段は、酸化数が変わらない）。

3つの式から NO と NO2 を消すと、全体の式になる。

NH3 + 2O2 → HNO3 + H2O

リン

同素体性質保存
黄リン（白リン） P4淡黄色のろう状の固体、有毒。空気中で自然発火する水中
赤リン赤褐色の粉末、毒性が低い。マッチ箱の側薬に使うそのまま

性質と保存法は覚える覚える。黄リンを水中に保存するのは、空気中の O2 と反応して自然発火するのを防ぐためである。

リンの燃焼酸化還元
4P + 5O2 → P4O10

P は 0 から ＋5 に酸化される。

十酸化四リンと水酸塩基
P4O10 + 6H2O → 4H3PO4

酸性酸化物と水の反応で、P は ＋5 のまま。P4O10 は水を強く吸収するので、酸性の乾燥剤・脱水剤に使う。

リン鉱石から過リン酸石灰酸塩基
Ca3(PO4)2 + 2H2SO4 → Ca(H2PO4)2 + 2CaSO4

水に溶けにくいリン酸カルシウムに硫酸を加え、水に溶けるリン酸二水素カルシウムにして肥料にする。強い酸から H+ を受け取る反応である。この Ca(H2PO4)2 と CaSO4 の混合物を過リン酸石灰という。
