気体の発生

実験室での気体の製法は、ほとんどが弱酸・弱塩基・揮発性の酸の遊離（酸塩基）か、酸化剤と還元剤の反応（酸化還元）である。

酸塩基で書ける製法・酸化還元で書ける製法・2つの道具で書けない製法・捕集法：水への溶けやすさと重さで決まる・乾燥剤：気体と反応しないものを選ぶ・色・におい・検出・過去問で確かめる

先に要るもの：酸塩基、酸化還元、反応はどちらへ進むか

酸塩基で書ける製法

弱酸・弱塩基・揮発性の酸の遊離。どの式でも酸化数は変わらない。行を開くと式が出る。

気体試薬加熱捕集
CO2炭酸カルシウム＋希塩酸不要下方
二酸化炭素酸塩基→電離しにくい分子になる→気体が出ていく
CaCO3 + 2HCl → CaCl2 + H2O + CO2
H2S硫化鉄(Ⅱ)＋希硫酸不要下方
硫化水素酸塩基→電離しにくい分子になる→気体が出ていく
FeS + H2SO4 → FeSO4 + H2S
SO2亜硫酸ナトリウム＋希硫酸不要下方
二酸化硫黄（弱酸の遊離）酸塩基→電離しにくい分子になる→気体が出ていく
Na2SO3 + H2SO4 → Na2SO4 + H2O + SO2

SO32− が H+ を受け取って H2SO3 になり、H2O と SO2 に分かれる。S は ＋4 のまま。

NH3塩化アンモニウム＋水酸化カルシウム要上方
アンモニア酸塩基→電離しにくい分子になる→気体が出ていく
2NH4Cl + Ca(OH)2 → CaCl2 + 2H2O + 2NH3

装置と乾燥は窒素のページ。

HCl塩化ナトリウム＋濃硫酸要下方
塩化水素酸塩基→気体が出ていく
NaCl + H2SO4 → NaHSO4 + HCl

なぜ進むかは反応はどちらへ進むか。

HFホタル石＋濃硫酸要—
フッ化水素酸塩基→電離しにくい分子になる→気体が出ていく
CaF2 + H2SO4 → CaSO4 + 2HF
C2H2炭化カルシウム＋水不要水上
アセチレン酸塩基→気体が出ていく
CaC2 + 2H2O → Ca(OH)2 + C2H2

C22− が水から H+ を2個受け取る。C の酸化数は −1 のまま。

酸化還元で書ける製法

酸化剤と還元剤の反応。式の出し方は、それぞれのページにある。

気体試薬加熱捕集
H2亜鉛＋希硫酸不要水上
水素酸化還元
Zn + H2SO4 → ZnSO4 + H2

酸の H+ が酸化剤（酸化還元のページ）。

O2過酸化水素水＋酸化マンガン(Ⅳ)不要水上
酸素（過酸化水素）酸化還元理論：反応速度・触媒
2H2O2 → 2H2O + O2

H2O2 の一部が酸化剤、残りが還元剤としてはたらく（O は −1 から −2 と 0 に分かれる）。MnO2 は触媒。

式の出し方
H2O2 + 2H+ + 2e− → 2H2O半反応式
H2O2 → O2 + 2H+ + 2e−
O2塩素酸カリウム＋酸化マンガン(Ⅳ)要水上
酸素（塩素酸カリウム）酸化還元
2KClO3 → 2KCl + 3O2
Cl2酸化マンガン(Ⅳ)＋濃塩酸要下方
塩素酸化還元
MnO2 + 4HCl → MnCl2 + Cl2 + 2H2O

装置と式の出し方はハロゲンのページ。高度さらし粉と塩酸なら加熱は要らない。

SO2銅＋濃硫酸要下方
二酸化硫黄（熱濃硫酸）酸化還元
Cu + 2H2SO4 → CuSO4 + SO2 + 2H2O
NO銅＋希硝酸不要水上
一酸化窒素酸化還元
3Cu + 8HNO3 → 3Cu(NO3)2 + 2NO + 4H2O

式の出し方は酸化還元のページ。

NO2銅＋濃硝酸不要下方
二酸化窒素酸化還元
Cu + 4HNO3 → Cu(NO3)2 + 2NO2 + 2H2O
N2亜硝酸アンモニウム要水上
窒素酸化還元
NH4NO2 → N2 + 2H2O

NH4+ の N（−3）と NO2− の N（＋3）が、ともに 0 の N2 になる。

2つの道具で書けない製法

気体試薬加熱捕集
COギ酸＋濃硫酸要水上
一酸化炭素覚える
HCOOH → H2O + CO

濃硫酸の脱水作用。C の酸化数は ＋2 のままで、H+ のやりとりでもない。

O3酸素（無声放電・紫外線）——
オゾン覚える
3O2 → 2O3

同素体への変化で、O の酸化数は 0 のまま。

捕集法：水への溶けやすさと重さで決まる

理論：気体の性質

NO は空気中の O2 とすぐ反応して NO2 になる（2NO + O2 → 2NO2）ので、空気にふれる置換法では集めない。

乾燥剤：気体と反応しないものを選ぶ

酸性の乾燥剤は塩基性の気体と、塩基性の乾燥剤は酸性の気体と中和するので使えない。Cl2・NO2 も塩基と反応して吸収されるので、塩基性の乾燥剤は使えない。

乾燥剤性質使えない気体理由
濃硫酸酸性NH3・H2SNH3 は中和酸塩基、H2S は酸化される酸化還元
十酸化四リン P4O10酸性NH3中和酸塩基
塩化カルシウム CaCl2中性NH3CaCl2·8NH3 をつくる覚える
酸化カルシウム CaO・ソーダ石灰塩基性CO2・SO2・HCl・H2S・Cl2・NO2CO2・SO2・HCl・H2S は中和酸塩基、Cl2・NO2 は塩基と反応して酸化数が変わる酸化還元

色・におい・検出

色・においと検出のしかたは覚える。色がある気体は Cl2（黄緑色）・NO2（赤褐色）・O3（淡青色）・F2（淡黄色）。刺激臭は Cl2・HCl・SO2・NH3・NO2・HF、腐卵臭は H2S、特異臭は O3。

気体検出のしかた道具
CO2石灰水が白くにごる（CaCO3）酸塩基
NH3・HCl濃塩酸・アンモニア水を近づけると白煙（NH4Cl）。NH3 は湿った赤色リトマス紙を青にする酸塩基
Cl2・O3湿ったヨウ化カリウムデンプン紙が青紫色になる（I− が I2 に酸化される）酸化還元
H2S酢酸鉛(Ⅱ)水溶液をしみこませたろ紙が黒くなる（PbS）覚える
SO2ヨウ素溶液の色を消す（SO2 が還元剤）酸化還元
NO空気にふれると赤褐色になる（NO2）酸化還元
O2火のついた線香が炎をあげて燃える覚える
H2・CO点火すると燃える（CO は青白い炎）酸化還元
