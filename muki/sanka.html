酸化還元

酸化剤と還元剤が何に変わるかが分かれば、半反応式は O・H・電荷をそろえるだけで書ける。

酸化数・半反応式の作り方・主な酸化剤・還元剤・半反応式を足して全体の式にする・金属と酸・水・酸化数の地図に出てくる3つの形・過去問で確かめる

先に要るもの：何をやりとりする反応か

酸化数

酸化数は、化合物やイオンの中の原子が、どれだけ電子を失ったか（＋）、得たか（−）を表す数である。次の順に決める。

  1. 単体の原子は 0。
  2. 化合物の中のアルカリ金属は ＋1、アルカリ土類金属は ＋2。
  3. 化合物の中の H は ＋1、O は −2。ただし、金属の水素化物（NaH など）の H は −1、過酸化物（H2O2 など）の O は −1。
  4. 化合物では酸化数の和が 0、イオンでは和がイオンの電荷に等しい。

例：Cr2O72− の Cr を x とすると、2x ＋ 7×(−2) ＝ −2 より x ＝ ＋6。MnO4− の Mn は ＋7、SO42− の S は ＋6、NO3− の N は ＋5 である。

酸化数が増えた原子は酸化された（電子を失った）、減った原子は還元された（電子を得た）。相手を酸化する物質が酸化剤で、酸化剤自身は還元される。

半反応式の作り方

酸化剤（または還元剤）が何に変わるかを書いたら、あとは次の順にそろえる。

  1. 酸化数が変わる原子の数をそろえる。
  2. O の数を、H2O を足してそろえる。
  3. H の数を、H+ を足してそろえる。
  4. 電荷を、e− を足してそろえる。
  5. 中性・塩基性の水溶液のときは、できた式の H+ の数だけ両辺に OH− を足し、H+ と OH− を H2O にまとめる。

例：酸性の過マンガン酸イオン MnO4− は Mn2+ になる。

MnO4− → Mn2+半反応式
MnO4− → Mn2+ + 4H2O
MnO4− + 8H+ → Mn2+ + 4H2O
MnO4− + 8H+ + 5e− → Mn2+ + 4H2O

最後の段で、左辺の電荷は −1＋8＝＋7、右辺は ＋2 なので、左辺に e− を5個足す。Mn の酸化数は ＋7 から ＋2 へ5減っているので、受け取る電子が5個であることとも合う。

例：二クロム酸イオン（酸性）。Cr を2個にそろえてから同じ順に進める。

Cr2O72− + 14H+ + 6e− → 2Cr3+ + 7H2O半反応式

例：中性・塩基性の MnO4− は MnO2 になる。4までで MnO4− + 4H+ + 3e− → MnO2 + 2H2O、両辺に 4OH− を足して H2O にまとめると、次の式になる。

MnO4− + 2H2O + 3e− → MnO2 + 4OH−半反応式

例：二酸化硫黄が還元剤としてはたらき、硫酸イオンになる。O は左辺に H2O を足してそろえる。

SO2 + 2H2O → SO42− + 4H+ + 2e−半反応式

主な酸化剤・還元剤

覚えるのは「何に変わるか」だけである。半反応式はそこから上の手順で出せる。

H2O2 と SO2 は、相手しだいで酸化剤にも還元剤にもなる。KMnO4 のような強い酸化剤に対しては還元剤、KI（H2O2 の場合）や H2S（SO2 の場合）のような還元剤に対しては酸化剤としてはたらく。

半反応式を足して全体の式にする

  1. 酸化剤と還元剤の半反応式を書く。
  2. e− の数がそろうように何倍かして足し、e− を消す（イオン反応式）。
  3. 反応に関わらなかったイオンを両辺に同じ数だけ足して、化学反応式にする。
硫酸酸性の過マンガン酸カリウムと過酸化水素酸化還元理論：滴定と量的関係
MnO4− + 8H+ + 5e− → Mn2+ + 4H2O　（×2）半反応式
H2O2 → O2 + 2H+ + 2e−　（×5）
2MnO4− + 6H+ + 5H2O2 → 2Mn2+ + 8H2O + 5O2イオン反応式
2KMnO4 + 3H2SO4 + 5H2O2 → 2MnSO4 + K2SO4 + 8H2O + 5O2

最後の段で、両辺に 2K+ と 3SO42− を足した。酸性にするのに硫酸を使うのは、塩酸だと Cl− が MnO4− に酸化され、硝酸だと硝酸自身が酸化剤としてはたらくからである。

銅と希硝酸酸化還元酸塩基
Cu → Cu2+ + 2e−　（×3）半反応式
HNO3 + 3H+ + 3e− → NO + 2H2O　（×2）
3Cu + 2HNO3 + 6H+ → 3Cu2+ + 2NO + 4H2Oイオン反応式
3Cu + 8HNO3 → 3Cu(NO3)2 + 2NO + 4H2O

両辺に 6NO3− を足した。8個の HNO3 のうち2個が酸化剤として NO になり、6個は酸として H+ を出し、NO3− は Cu2+ と塩をつくる。

量的関係も電子で決まる。酸化剤が受け取る e− の物質量と、還元剤が与える e− の物質量は等しい。上の例では、KMnO4 1 mol は e− を 5 mol、H2O2 1 mol は 2 mol やりとりするので、物質量の比は KMnO4：H2O2 ＝ 2：5 になる。

金属と酸・水

理論：電池・電気分解

どちら向きに進むか（強い酸化剤と強い還元剤から弱い側ができる）は反応はどちらへ進むかにまとめた。金属は還元剤で、イオン化傾向の大きいものほど強い。

H₂ より陽イオンになりやすい金属と希酸酸化還元
Zn → Zn2+ + 2e−半反応式
2H+ + 2e− → H2
Zn + 2HCl → ZnCl2 + H2

酸の H+ が酸化剤としてはたらき、水素が発生する。

Cu・Ag と酸化力のある酸酸化還元

Cu や Ag は H+ では酸化されない。希硝酸・濃硝酸・熱濃硫酸のように、H+ より強い酸化剤（NO3−、H2SO4）を含む酸には溶ける。発生する気体は水素ではなく、NO・NO2・SO2 である。

Cu + 4HNO3 → Cu(NO3)2 + 2NO2 + 2H2O
Cu + 2H2SO4 → CuSO4 + SO2 + 2H2O

Pt と Au は、濃硝酸と濃塩酸を 1：3 の体積比で混ぜた王水にだけ溶ける。

反応が進まない組合せ覚える

Al・Fe・Ni は濃硝酸に入れると表面にち密な酸化物の膜ができ、内部まで反応が進まない（不動態）。Pb は希塩酸・希硫酸と反応すると表面が難溶性の PbCl2・PbSO4 でおおわれ、反応がほとんど進まない。どちらも半反応式からは出てこないので覚える。

金属と水酸化還元覚える
2Na + 2H2O → 2NaOH + H2

水の H（＋1）が還元されて H2 になる。どの金属がどの条件で水と反応するか（Na・K・Ca は常温の水、Mg は熱水、Al・Zn・Fe は高温の水蒸気）は覚える。

酸化数の地図に出てくる3つの形

酸化還元

元素ごとの地図を並べると、元素がちがっても同じ形がくり返し出てくる。1つの元素で分かった形は、ほかの元素にもそのまま使える。

形1　はしごの上と下は価電子の数で決まる

非金属元素の原子は、価電子をすべて出したときが最高の酸化数（Cl ＋7、S ＋6、N ＋5、C ＋4）、貴ガスと同じ電子配置になるまで電子を受け取ったときが最低の酸化数（Cl −1、S −2、N −3、C −4）になる。いちばん下の段の物質は、それ以上還元されないので酸化剤にはなれない（はたらくとすれば還元剤）。いちばん上の段の物質は、還元剤にはなれない。実際にどれだけ強くはたらくかは物質ごとにちがい、H2S は強い還元剤だが、Cl− は MnO2 のような強い酸化剤にだけ酸化される。

形2　真ん中の物質が、上と下に分かれる
Cl2 + H2O ⇄ HCl + HClO
3NO2 + H2O → 2HNO3 + NO
2H2O2 → 2H2O + O2

1種類の物質が酸化剤と還元剤を兼ね、酸化数が上と下に分かれる（Cl：0 → −1・＋1、N：＋4 → ＋5・＋2、O：−1 → −2・0）。それぞれ塩素と水・オストワルト法・酸素の製法。

形3　上と下の物質が、真ん中に集まる
SO2 + 2H2S → 3S + 2H2O
ClO− + Cl− + 2H+ → Cl2 + H2Oイオン反応式
NH4NO2 → N2 + 2H2O

同じ元素の、酸化数の高い物質と低い物質が反応して、間の酸化数の物質になる（S：＋4・−2 → 0、Cl：＋1・−1 → 0、N：＋3・−3 → 0）。それぞれ二酸化硫黄と硫化水素・高度さらし粉と塩酸・窒素の製法。

SO2・H2O2 が相手しだいで酸化剤にも還元剤にもなるのは、真ん中の酸化数にいて、上にも下にも動けるからである。Cl2・NO2 は、水との反応で1つの物質の中で上と下に分かれる（形2）。形2と形3は、真ん中の物質のこの性質の表と裏になっている。
