酸素・硫黄

硫黄の化合物は、S の酸化数が −2（H₂S）・0（S）・＋4（SO₂）・＋6（H₂SO₄）の間を行き来する。

反応の地図（硫黄）

つながる地図：窒素（接触法とオストワルト法は同じ形）・ハロゲン（酸化数の範囲が同じ形）・上と下の酸化数が真ん中に集まる反応（SO₂＋H₂S）

酸素とオゾン・硫黄の単体・硫化水素・二酸化硫黄・硫酸：濃度と温度で4つのはたらき・接触法・過去問で確かめる

先に要るもの：半反応式の作り方、反応はどちらへ進むか

酸素とオゾン

酸素 O2 とオゾン O3 は同素体である。O3 は淡青色で特異臭のある気体で、強い酸化作用をもつ。

オゾンとヨウ化カリウム酸化還元
O3 + 2H+ + 2e− → O2 + H2O半反応式
2I− → I2 + 2e−
O3 + 2KI + H2O → O2 + I2 + 2KOH

中性の水溶液なので、半反応式を足したあと両辺の H+ を H2O と OH− に直してある（両辺に 2OH− を足す）。ヨウ化カリウムデンプン紙が青紫色になるので、O3 の検出に使う。

酸素の製法は気体の発生のページ。工業的には液体空気の分留でつくる。

硫黄の単体

硫黄には斜方硫黄・単斜硫黄・ゴム状硫黄の同素体がある覚える。常温で安定なのは斜方硫黄。

硫黄の燃焼酸化還元
S + O2 → SO2

空気中で青い炎をあげて燃える。S は 0 から ＋4 に酸化される。

硫化水素

無色・腐卵臭の有毒な気体で、水に少し溶けて弱い酸性を示す（H2S ⇄ H+ + HS−）。S の酸化数は −2 で最も低いので、還元剤としてはたらく。

製法（弱酸の遊離）酸塩基→電離しにくい分子になる→気体が出ていく
FeS + H2SO4 → FeSO4 + H2S
二酸化硫黄との反応酸化還元→強い酸化剤と強い還元剤から
SO2 + 4H+ + 4e− → S + 2H2O半反応式
H2S → S + 2H+ + 2e−　（×2）
SO2 + 2H2S → 3S + 2H2O

ふだん還元剤としてはたらく SO2 が、より強い還元剤の H2S に対しては酸化剤になる。どちらの S も 0 の S になり、溶液が白くにごる。

金属イオンとの沈殿覚える→沈殿して抜ける理論：電離平衡

H2S は多くの金属イオンと硫化物の沈殿をつくる。CuS・PbS・Ag2S は黒色で、酸性でも沈殿する。ZnS（白色）・FeS（黒色）は中性・塩基性で沈殿する。覚えることのページにまとめている。

二酸化硫黄

無色・刺激臭の気体で、水に溶けて弱い酸性を示す。S の酸化数は ＋4 で、−2 と ＋6 の間にあるので、ふつうは還元剤、より強い還元剤に対しては酸化剤としてはたらく。

製法酸化還元酸塩基→気体が出ていく
Cu + 2H2SO4 → CuSO4 + SO2 + 2H2O　（熱濃硫酸）
Na2SO3 + H2SO4 → Na2SO4 + H2O + SO2

1つ目は酸化還元、2つ目は弱酸の遊離である。

還元剤としてのはたらき酸化還元
SO2 + 2H2O → SO42− + 4H+ + 2e−半反応式

漂白作用は、この還元作用による。

硫酸：濃度と温度で4つのはたらき

希硫酸：強酸酸塩基→電離しにくい分子になる
2CH3COONa + H2SO4 → Na2SO4 + 2CH3COOH

強酸として H+ を出し、弱酸を遊離させる。亜鉛などの金属とは H+ が酸化剤になって H2 を出す（気体の発生）。

濃硫酸：不揮発性酸塩基→気体が出ていく
NaCl + H2SO4 → NaHSO4 + HCl

沸点が高く揮発しにくいので、揮発性の酸を追い出す（反応はどちらへ進むか）。

熱濃硫酸：酸化作用酸化還元
H2SO4 + 2H+ + 2e− → SO2 + 2H2O半反応式

加熱した濃硫酸は、Cu や Ag のような H2 よりイオン化傾向の小さい金属も溶かす。

濃硫酸：脱水作用と吸湿性覚える理論：反応エンタルピー

有機化合物から H と O を水の形で引き抜く（ギ酸から CO、スクロースの炭化）。水分を吸収しやすいので乾燥剤に使う。希釈するときは、発熱が大きいので、水に濃硫酸を少しずつ加える。

接触法

硫酸の工業的製法酸化還元酸塩基理論：化学平衡理論：反応速度・触媒理論：反応エンタルピー
S + O2 → SO2
2SO2 + O2 → 2SO3　（触媒 V2O5）
SO3 + H2O → H2SO4

1段目・2段目は S が 0 → ＋4 → ＋6 と酸化される酸化還元。3段目は酸性酸化物 SO3 と水の反応で、酸化数は変わらない。実際には SO3 を濃硫酸に吸収させて発煙硫酸とし、希硫酸で薄めて濃硫酸にする。触媒が酸化バナジウム(Ⅴ) V2O5 であることは覚える覚える。

2段目（2SO2 + O2 ⇄ 2SO3）は発熱反応で、気体の分子が 3 個から 2 個に減る。平衡だけを考えれば低温・高圧ほど SO3 が多くなるが、低温では反応が遅いので、触媒を使ってある程度の高温で行う。考え方はハーバー・ボッシュ法と同じである。

流れはオストワルト法と同じ形をしている。どちらも、酸化を重ねて酸化物にし、水と反応させて酸にする。ちがいは最後の段で、SO3 + H2O → H2SO4 は S が ＋6 のまま（どの原子の酸化数も変わらない）、3NO2 + H2O → 2HNO3 + NO は N が ＋5 と ＋2 に分かれる酸化還元である。
