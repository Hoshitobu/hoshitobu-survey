アルカリ金属・アルカリ土類金属

1族・2族の金属は陽イオンになりやすい強い還元剤で、その酸化物と水酸化物は塩基である。

反応の地図（ナトリウムとカルシウム）

つながる地図：ハロゲン（NaCl の電気分解で Cl₂）・炭素（CO₂ が出入りする反応）・窒素（NH₃ の製法とアンモニアソーダ法）

単体・酸化物・水酸化物・炭酸ナトリウム・炭酸水素ナトリウム・カルシウム・マグネシウムの化合物・炎色反応・過去問で確かめる

先に要るもの：半反応式の作り方、反応はどちらへ進むか

単体

酸化還元

アルカリ金属（Li・Na・K など）は価電子を1個、アルカリ土類金属（Be・Mg・Ca・Sr・Ba など）は2個もち、それぞれ1価・2価の陽イオンになりやすい。どちらもイオン化傾向が大きく、強い還元剤である。

水との反応
2Na + 2H2O → 2NaOH + H2
Ca + 2H2O → Ca(OH)2 + H2
Mg + 2H2O → Mg(OH)2 + H2　（熱水）

金属が電子を与え、水の H（＋1）が受け取って H2 になる。アルカリ金属と Ca・Sr・Ba は常温の水と、Mg は熱水と反応する覚える。Na や K は水や空気中の O2 と反応するので、石油（灯油）中に保存する覚える。

酸素との反応
4Na + O2 → 2Na2O
2Mg + O2 → 2MgO

Mg は空気中で強い光を出して燃える。

単体の製法（溶融塩電解）理論：電池・電気分解
Na+ + e− → Na　（陰極）半反応式
2Cl− → Cl2 + 2e−　（陽極）

水溶液を電気分解すると陰極では水が還元されて H2 が出るので、水を含まない融解した塩化ナトリウムを電気分解する。

酸化物・水酸化物

塩基性酸化物と水酸塩基理論：反応エンタルピー
Na2O + H2O → 2NaOH
CaO + H2O → Ca(OH)2

酸化カルシウム（生石灰）は水と反応して多量の熱を出し、水酸化カルシウム（消石灰）になる。

水酸化ナトリウムと二酸化炭素酸塩基
2NaOH + CO2 → Na2CO3 + H2O

NaOH の固体は空気中の水分を吸収して溶ける（潮解）。さらに空気中の CO2 を吸収して Na2CO3 になる。

水酸化ナトリウムの工業的製法（イオン交換膜法）酸化還元理論：電池・電気分解
2Cl− → Cl2 + 2e−　（陽極）半反応式
2H2O + 2e− → H2 + 2OH−　（陰極）
2NaCl + 2H2O → 2NaOH + H2 + Cl2

陽イオン交換膜は Na+ だけを陰極側へ通す。陰極側に Na+ と OH− が集まり、NaOH が得られる。

炭酸ナトリウム・炭酸水素ナトリウム

酸との反応酸塩基→電離しにくい分子になる→気体が出ていく
Na2CO3 + 2HCl → 2NaCl + H2O + CO2
NaHCO3 + HCl → NaCl + H2O + CO2

どちらも弱酸の遊離。水溶液は、Na2CO3 が塩基性、NaHCO3 が弱い塩基性である。

炭酸ナトリウム十水和物の風解覚える

Na2CO3·10H2O の結晶は、空気中に置くと水和水を失って粉末になる（風解）。

アンモニアソーダ法（ソルベー法）酸塩基覚える
NaCl + H2O + NH3 + CO2 → NaHCO3 + NH4Cl
2NaHCO3 → Na2CO3 + H2O + CO2
CaCO3 → CaO + CO2
CaO + H2O → Ca(OH)2
Ca(OH)2 + 2NH4Cl → CaCl2 + 2H2O + 2NH3

どの段も酸化数は変わらず、すべて酸塩基で書ける。1段目は、NH3 を溶かして塩基性にした食塩水に CO2 を通すと、CO2 が H+ を出して HCO3− になり、NH3 が受け取って NH4+ になる。NaHCO3 が沈殿するのは、この中で比較的水に溶けにくいからで、ここは覚える覚える。最後の段は弱塩基の遊離で、NH3 を回収してまた使う。2段目の NaHCO3 の熱分解は、HCO3− どうしの H+ のやりとりと読める（酸塩基のページ）。

1段目の式を2倍し、5つの式を足して途中の物質を消すと、全体の式になる。ただし、この全体の式の反応（NaCl と CaCO3 から直接）が起こるわけではない。

2NaCl + CaCO3 → Na2CO3 + CaCl2

カルシウム・マグネシウムの化合物

炭酸カルシウム酸塩基
CaCO3 → CaO + CO2　（加熱）
CaCO3 + 2HCl → CaCl2 + H2O + CO2

石灰石・大理石の主成分。石灰水に CO2 を通したときの反応は炭素のページ。

硫酸塩と炭酸塩の溶けやすさ覚える→沈殿して抜ける

CaSO4・BaSO4 は水に溶けにくく、MgSO4 は溶ける。BaSO4 は酸にも溶けにくく、X線の造影剤に使う。炭酸塩（CaCO3・BaCO3・MgCO3）はどれも水に溶けにくい。硫酸カルシウムの二水和物はセッコウで、加熱して得られる焼きセッコウ（CaSO4·½H2O）は水を加えると固まる。

塩化カルシウム覚える

水に溶けやすく、吸湿性が強いので乾燥剤に使う（NH3 には使えない。乾燥剤の表）。

Mg が Ca とちがう所：熱水と反応する（Ca は常温の水と反応する）、水酸化物 Mg(OH)2 は水に溶けにくい弱塩基（Ca(OH)2 は水に少し溶けて強塩基）、硫酸塩 MgSO4 は水に溶ける、炎色反応を示さない。

炎色反応

Li 赤、Na 黄、K 赤紫、Ca 橙赤、Sr 紅、Ba 黄緑（Be・Mg は示さない）。表は覚えることのページ。
